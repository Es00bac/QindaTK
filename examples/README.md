# Examples

Most examples are plain QML files run by `qtk-preview` and each standalone
`examples/<name>/Main.qml` is a ctest smoke test (`example_<name>`). The
`workbench` example has a C++ host and its own `--check` gate, so its QML
file is not run directly by `qtk-preview`. Screenshots are regenerated by
`tools/scripts/screenshots.sh` into `docs/screenshots/`.

```
P=build/dev/tools/preview/qtk-preview
$P examples/gallery/Main.qml                       # on screen
$P examples/gallery/Main.qml --dump | less         # geometry without a screen
$P examples/gallery/Main.qml --grab out.png --density comfortable
```

## smoke

The smallest useful screen: a canvas with a zoom island beside an
inspector panel whose body scrolls a section header and a two-column
`Tk.Grid` of readouts. Start here to see how `Flex`, `Box`, `Scroll`,
`Panel` and the text family fit together.

- Run: `qtk-preview examples/smoke/Main.qml --dump`
- Exercises: `Flex`, `Box`, `Panel`, `Scroll`, `Grid`, `Island`,
  `SectionHeader`, `Divider`, `IconButton`, `Caption`, `Mono`, `Label`

## layout-diagnostics

A focused geometry scene for the WP-006 layout and scrolling work. Stable
object names in its dump cover baseline alignment, intrinsic wrapping, invalid
Grid syntax, RTL mirroring, per-side Box edges, and nested Scroll viewports.
The companion [WP-006 diagnostic report](../docs/universal-toolkit/implementation/evidence/WP-006-diagnostics.md)
records the current observations and unresolved contracts.

- Run: `qtk-preview examples/layout-diagnostics/Main.qml --dump --size 960x760`
- Screenshot: `qtk-preview examples/layout-diagnostics/Main.qml --grab out.png --size 960x760`
- Screenshot: [docs/screenshots/smoke.png](../docs/screenshots/smoke.png),

## adaptive-layout

A 360×300 narrow inspector scene exercises a wrapped action row, auto-fill
Grid cards, and a Stack overlay with a long message and a reserved badge slot.
The sections flow by content height inside `Tk.Scroll`, including at 2× text
size. Set `interfaceDirection` to `Qt.RightToLeft` to inspect mirrored
placement. The focused `tst_layout` matrix checks both densities, both
directions, and normal/2× text.

- Run: `qtk-preview examples/adaptive-layout/Main.qml --dump --size 360x300`
- Screenshot: `qtk-preview examples/adaptive-layout/Main.qml --grab out.png --density comfortable --size 360x300`
- Exercises: `Flex.Wrap`, responsive `Grid` auto-fill, `Stack` overlay insets, long-label wrapping, density-aware spacing, and logical direction

## gallery

The core controls in [docs/controls.md](../docs/controls.md) in their common
documented states — variants, sizes, checked/disabled/busy/error, selected
and two-line rows, expanded and collapsed tree rows — grouped by section with a header
that switches the preset and the density live and a search field that
filters sections by title. The header wraps as text grows; at maximum
Touch/text zoom its preset switch scrolls horizontally so every choice stays
reachable. One QML file per section (`TextSection.qml`,
`LayoutSection.qml`, …); `Section.qml` and `GalleryRow.qml` are the two
layout helpers.

- Run: `qtk-preview examples/gallery/Main.qml`
  (`--theme sloom-light`, `--density comfortable`, `--size 1280x3400` to see
  the whole page at once)
- Exercises: the original 62-control gallery set, including `DockHost` (an embedded dock with a
  tab group), `Menu`/`MenuBar`/`Popover`/`Dialog`/`CommandPalette` (opened
  from buttons), `Splitter`, `Ruler`, `ZoomControl`, and a swatch of every
  `Tk.Theme.color` role
- Screenshot: [docs/screenshots/gallery.png](../docs/screenshots/gallery.png),
  [gallery-comfortable.png](../docs/screenshots/gallery-comfortable.png),
  [gallery-light.png](../docs/screenshots/gallery-light.png)

## selection_overlay

A focused spatial overlay scene that shows a document-space selection mapped
through a rotated canvas view into eight accessible transform handles. It
reports gestures to a host; snapping and commits belong to WP-041.

- Run: `qtk-preview examples/selection_overlay/selection_overlay.qml --check --size 960x600`
- Evidence: [WP-041 overlay proof](../docs/universal-toolkit/implementation/evidence/WP-041.md)

## spatial-canvas

Two canvas views share one document, navigation pose and `CanvasSelectionModel`.
Each view has its own `ToolController`; selecting in either view updates the
other while document edits prune removed or hidden objects.

- Run: `qtk-preview examples/spatial-canvas/Main.qml --check --size 1280x800`
- Alignment demo: `qtk-preview examples/spatial-canvas/AlignWorkingScene.qml --check --size 900x520`

## docking

`Tk.DockHost` with a source bin on the left, an inspector and a
Layers/Channels/Paths tab group on the right, a program monitor in the
centre zone above the canvas, a timeline at the bottom and a floating
History panel. Drag headers to tear off and re-dock, drag seams to resize
lanes and shares, right-click tabs for the group menu; the top bar floats,
hides, shows and resets panels through the host API.

- Run: `qtk-preview examples/docking/Main.qml`
  (`--dump | grep dockZone` lists the zones and lanes)
- Exercises: `DockHost`, `DockPanel`, `DockModel` operations, `Island`,
  `SectionHeader`, `Grid`, `Box`, `Repeater` inside `Flex`
- Screenshot: [docs/screenshots/docking.png](../docs/screenshots/docking.png)

## studio-shell

Sloom Studio's Video workspace rebuilt from QindaTK: workspace chips and
the project field, a `MenuBar` whose View menu lists the dock's panels
(`DockHost.panelMenuModel`) with checkable items, a `DockHost` holding the
Project Source Bin (left), Source and Program monitors side by side in the
centre zone, Inspector and Selected-clip panels (right), the timeline as
the dock canvas (chip tool row, a seconds `Ruler`, a `Grid` of track
headers and lanes, clips as boxes with a striped thumbnail band, a
playhead in a `Stack`), and a `StatusBar`. Panels are one file each
(`SourceBinPanel.qml`, `MonitorPanel.qml`, `InspectorPanel.qml`,
`ClipPanel.qml`, `TimelineCanvas.qml`).

- Run: `qtk-preview examples/studio-shell/Main.qml`
  (`--qst qinda-dusk` renders it under a QindaQt desktop theme through the
  `QindaTK.QindaQt` bridge)
- Exercises: `DockHost`/`DockPanel`, `MenuBar`/`Menu`/`MenuItem` with an
  `Instantiator`, `Chip`, `TextField`, `Island`, `ZoomControl`, `Badge`,
  `TabStrip`, `Segmented`, `Card`, `Notice`, `PropertyGroup`/`PropertyRow`/
  `KeyValue`, `NumberField`, `ComboBox`, `Slider`, `Switch`, `Button`,
  `Ruler`, `Grid`, `Stack`, `StatusBar`/`StatusField`
- Screenshot: [docs/screenshots/studio-shell.png](../docs/screenshots/studio-shell.png),
  [studio-shell-qinda-dusk.png](../docs/screenshots/studio-shell-qinda-dusk.png)

## rich-document

Rich text and pages (WP-050): one `Tk.RichTextDocument` shown as pages in a
`RichDocumentView` and as a continuous draft in a `RichTextEditor`. A
`FormatBar` follows whichever of the two has focus, and a `PageNavigator`
shows thumbnails and an outline. `showcase.qtkrich` is a native
`qindatk.richtext/1` file containing:

- mixed scripts, lists, a link and an inline image;
- a 30-row table that crosses a page break with a repeated header;
- a float that moves with its anchor, and a page stamp;
- a page-break appendix with right-to-left paragraphs.

- Run: `qtk-preview examples/rich-document/Main.qml`
  (`--dump --size 1280x800` lists `richDocumentPage_<pageKey>` for the
  visible pages only)
- Exercises: `RichTextDocument`, `RichDocumentView`, `RichTextEditor`,
  `FormatBar`, `PageNavigator`, `Panel`, `StatusBar`
- Screenshots: [compact](../docs/universal-toolkit/implementation/evidence/WP-050-compact.png),
  [comfortable](../docs/universal-toolkit/implementation/evidence/WP-050-comfortable.png)

## office-shell

A document application's window: `Tk.AppWindow` with a `MenuBar` (radio
items for the ink tools, a colour submenu built with a `Repeater`), two
wrapping `ToolBar`s with a `ColorButton`, a page inside a `Viewport` with a
zoom `Island`, a find bar band, a `StatusBar`, and the three dialogs an
editor needs (`MessageDialog` Save/Discard/Cancel and Delete, `PromptDialog`
rename). This is the shape the QindaQt office suite's windows take.

- Run: `qtk-preview examples/office-shell/Main.qml`
  (`--dump --size 520x700` shows the toolbars wrapping onto two rows)
- Exercises: `AppWindow`, `MenuBar`/`Menu`/`MenuItem { radio }`, `ToolBar { wrap }`,
  `ColorButton`, `Viewport`, `ZoomControl`, `Island`, `Stack`, `StatusBar`,
  `MessageDialog`, `PromptDialog`

## workbook

The WP-055 spreadsheet over a two-sheet budget, a workbook session of a
`DocumentManager` (`createDocument("qindatk.workbook.v1")`). `WorkbookTabs` switch
between the Budget and Summary sheets (whose formulas refer to Budget by
sheet ID, so renames and reordering keep them; the tab menu colors, hides
and protects sheets). The `FormulaBar` edits the active cell's source input
and shows its formatted value; Enter commits, Escape restores, and clicking
cells while editing a formula inserts their references. Select F2:F5 and
press Fill down (Ctrl+D) or drag the fill handle to complete the totals with
relative references moved. The Budget sheet has number formats, a frozen
header row and column, a data bar and a highlight rule, and a validated tax
rate (B8 warns above 50%). Summary uses the name `Totals`, a whole-column
`COUNTA(Budget!A:A)` and a merged note. The format toolbar applies bold,
italic, underline, alignment, number formats, a highlight fill, merges
and freeze panes to the selection; the side panel edits conditional formats
(with a live preview) and validation rules. Ctrl+C/Ctrl+V use the system
clipboard. Undo/Redo go through the manager's `UndoService`, which holds
the workbook's history. Save writes a `.qtkwb` file to the temporary
directory through the session on a worker, and Reopen saved closes the
session (discarding later changes) and opens the file again. The status line reports the revision and the last
recalculation's evaluated cells.

- Run: `qtk-preview examples/workbook/Main.qml`
- Dump: `qtk-preview examples/workbook/Main.qml --dump --size 1440x820`
- Exercises: `Workbook`, `DocumentManager`, `DocumentSession`, `UndoService`, `ClipboardService`,
  `SheetView` (over `EditableGrid`, `GridCellDelegate`, `GridFillHandle`),
  `FormulaBar`, `WorkbookTabs`, `ConditionalFormatEditor`,
  `DataValidationEditor`, `Segmented`, `ComboBox`, `MessageDialog`
  (sheet removal prompt), `Button`, `IconButton`
- Captures: [compact](../docs/universal-toolkit/implementation/evidence/WP-055-compact.png),
  [comfortable](../docs/universal-toolkit/implementation/evidence/WP-055-comfortable.png),
  [rejected formula](../docs/universal-toolkit/implementation/evidence/WP-055-formula-error.png)
