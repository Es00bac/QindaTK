# Examples

Every example is a plain QML file run by `qtk-preview`; nothing is compiled.
Each `examples/<name>/Main.qml` is also a ctest smoke test
(`example_<name>`), so an example that stops instantiating fails the
build's test gate. Screenshots are regenerated by
`tools/scripts/screenshots.sh` into `docs/screenshots/`.

```
P=build/dev/tools/preview/qtk-preview
$P examples/gallery/Main.qml                       # on screen
$P examples/gallery/Main.qml --dump | less         # geometry without a screen
$P examples/gallery/Main.qml --grab out.png --density comfortable
```

## smoke

The smallest useful screen: a canvas with a zoom island beside an
inspector panel whose body scrolls a section header and a two-column
`Tk.Grid` of readouts. Start here to see how `Flex`, `Box`, `Scroll`,
`Panel` and the text family fit together.

- Run: `qtk-preview examples/smoke/Main.qml --dump`
- Exercises: `Flex`, `Box`, `Panel`, `Scroll`, `Grid`, `Island`,
  `SectionHeader`, `Divider`, `IconButton`, `Caption`, `Mono`, `Label`
- Screenshot: [docs/screenshots/smoke.png](../docs/screenshots/smoke.png),
  [smoke-light-comfortable.png](../docs/screenshots/smoke-light-comfortable.png),
  [smoke-qinda-dark.png](../docs/screenshots/smoke-qinda-dark.png) (desktop theme via `--qst`)

## gallery

Every control in [docs/controls.md](../docs/controls.md) in every documented
state — variants, sizes, checked/disabled/busy/error, selected and two-line
rows, expanded and collapsed tree rows — grouped by section with a header
that switches the preset and the density live and a search field that
filters sections by title. One QML file per section (`TextSection.qml`,
`LayoutSection.qml`, …); `Section.qml` and `GalleryRow.qml` are the two
layout helpers.

- Run: `qtk-preview examples/gallery/Main.qml`
  (`--theme sloom-light`, `--density comfortable`, `--size 1280x3400` to see
  the whole page at once)
- Exercises: all 62 QML types, including `DockHost` (an embedded dock with a
  tab group), `Menu`/`MenuBar`/`Popover`/`Dialog`/`CommandPalette` (opened
  from buttons), `Splitter`, `Ruler`, `ZoomControl`, and a swatch of every
  `Tk.Theme.color` role
- Screenshot: [docs/screenshots/gallery.png](../docs/screenshots/gallery.png),
  [gallery-comfortable.png](../docs/screenshots/gallery-comfortable.png),
  [gallery-light.png](../docs/screenshots/gallery-light.png)

## docking

`Tk.DockHost` with a source bin on the left, an inspector and a
Layers/Channels/Paths tab group on the right, a program monitor in the
centre zone above the canvas, a timeline at the bottom and a floating
History panel. Drag headers to tear off and re-dock, drag seams to resize
lanes and shares, right-click tabs for the group menu; the top bar floats,
hides, shows and resets panels through the host API.

- Run: `qtk-preview examples/docking/Main.qml`
  (`--dump | grep dockZone` lists the zones and lanes)
- Exercises: `DockHost`, `DockPanel`, `DockModel` operations, `Island`,
  `SectionHeader`, `Grid`, `Box`, `Repeater` inside `Flex`
- Screenshot: [docs/screenshots/docking.png](../docs/screenshots/docking.png)

## studio-shell

Sloom Studio's Video workspace rebuilt from QindaTK: workspace chips and
the project field, a `MenuBar` whose View menu lists the dock's panels
(`DockHost.panelMenuModel`) with checkable items, a `DockHost` holding the
Project Source Bin (left), Source and Program monitors side by side in the
centre zone, Inspector and Selected-clip panels (right), the timeline as
the dock canvas (chip tool row, a seconds `Ruler`, a `Grid` of track
headers and lanes, clips as boxes with a striped thumbnail band, a
playhead in a `Stack`), and a `StatusBar`. Panels are one file each
(`SourceBinPanel.qml`, `MonitorPanel.qml`, `InspectorPanel.qml`,
`ClipPanel.qml`, `TimelineCanvas.qml`).

- Run: `qtk-preview examples/studio-shell/Main.qml`
  (`--qst qinda-dusk` renders it under a QindaQt desktop theme through the
  `QindaTK.QindaQt` bridge)
- Exercises: `DockHost`/`DockPanel`, `MenuBar`/`Menu`/`MenuItem` with an
  `Instantiator`, `Chip`, `TextField`, `Island`, `ZoomControl`, `Badge`,
  `TabStrip`, `Segmented`, `Card`, `Notice`, `PropertyGroup`/`PropertyRow`/
  `KeyValue`, `NumberField`, `ComboBox`, `Slider`, `Switch`, `Button`,
  `Ruler`, `Grid`, `Stack`, `StatusBar`/`StatusField`
- Screenshot: [docs/screenshots/studio-shell.png](../docs/screenshots/studio-shell.png),
  [studio-shell-qinda-dusk.png](../docs/screenshots/studio-shell-qinda-dusk.png)
