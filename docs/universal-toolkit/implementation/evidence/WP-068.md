# WP-068 — Pitch analysis and correction editing

**State: active; package not accepted.**

Luna's `work/wp068-pitch-editor` implementation was integrated from `29e5fbc`.
`PitchEditor` renders a bounded host-supplied pitch contour, note regions and
confidence, then issues pitch, time and formant preview/commit requests with
exact sample strings. The host owns limits, parameter state and edit outcomes.

The isolated build used configured `-j24 -l24`; its focused QML checks passed
2/2 and its preview fixture instantiated. The merged focused QML run passed
4/4 and `example_pitch-editor` passed. The merged dump places
`PitchEditor#pitchEditor` at `0,0 1096x560` and its canvas at `2,2 1092x556`.
The 1120×720 [pitch fixture screenshot](WP-068-pitch-editor.png) was opened
and inspected after tightening its sample pitch range around the notes.
Pitch detection, correction DSP, audio rendering,
persistent edits and undo remain required before acceptance.
