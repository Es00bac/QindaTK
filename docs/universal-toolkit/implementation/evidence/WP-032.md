# WP-032 — Event, diff and resource views

**State:** review. EventLogView, DiffView and ResourceTable are integrated, with
dedicated [event](WP-032-event-log.md), [diff](WP-032-DAT-19.md), and
[resource](WP-032-resource.md) evidence.

The combined Qt 6.11 build passed. The focused C++ tests
`tst_event_log_model`, `tst_diff_model`, and `tst_resource_plan_model`, both
DiffView/ResourceTable example smoke tests, and the three focused QML test
files passed. EventLog's startup tail assertion found a real failure during
integration; after deferring positioning until the ListView settled, it and
the paused-anchor test passed. Compact and comfortable EventLog captures were
inspected again with aligned columns and the latest row visible. The new
`tests/consumer/wp032` standalone application compiled against staged public
headers, imported all three installed views, and exercised event append,
revisioned diff, allocation and undo with exit status zero on Qt 6.11.
The same focused C++/QML checks and standalone installed consumer passed on
Qt 6.8.3. `DiffView` uses a QtQuick.Templates control root after integration;
its Qt 6.11 QML test and compact render were rerun and inspected after that
change, and its Qt 6.8 QML test passed as well.
The full Qt 6.11 repository regression completed **73/73** after integration.
