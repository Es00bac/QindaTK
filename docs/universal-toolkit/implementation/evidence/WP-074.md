# WP-074 — Node-based compositing

**State: active; package not accepted.**

`NodeGraph` is a reusable visual editor for host-supplied node and edge
snapshots. It exposes selection, position, connection and disconnection
requests with acknowledgments. The host fixture shows accepted compatible
links and rejected mismatched port types.

`NodeGraphModel` supplies a first functional image graph: stable typed
node/edge identities, cycle and port validation, source/solid/transform/blend
and output operations, incremental cache invalidation, local undo/redo and
versioned topology persistence. Host-owned source images are bound separately
from saved topology. The [live fixture](../../../../examples/node-graph-live/Main.qml)
connects the editor to the model and displays rendered pixels. The model's
focused merged QtTest passed 1/1, including the solid-node pixel check; the
NodeGraph QML test passed 3/3. The live fixture passed `qtk-preview --check`.
Its [1120×650 screenshot](WP-074-node-graph-live.png) was opened and inspected:
the three connections, four fully visible nodes and blended output are shown.
The geometry dump reports `NodeGraph#nodeGraph 0,0 718x575` and
`Image#nodeGraphRenderedOutput 0,19 370x180`.

See [node graph contract](../../../node-graph.md) for the data model and
limits. Remaining scope includes node search/grouping, a broader processing
set, integration with external media asset providers, and qualification of
large graphs and alternate Qt versions.
