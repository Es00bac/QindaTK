# WP-059 — Forms, schemas and report design

**State: active; package not accepted.**

The isolated Luna lane `work/wp059-forms-schema-report` (`a015b83`)
supplied `LocalDatabaseProvider` over SQLite plus `FormDesigner`,
`DatabaseSchemaView` and `ReportDesigner`. The provider performs parameter
bound reads/writes, inspects columns/keys/foreign keys, validates a single
schema statement before an explicit migration, and provides a basic
group/count report preview. The sample uses an in-memory fixture database.

The isolated build used the configured `-j24 -l24` limits. The focused
provider test passed 3/3, the QML workflow test passed 3/3, and the form
fixture and gallery instantiated. The [form/schema/report screenshot](WP-059-forms-schema-report.png)
was opened and inspected: form fields bind to data, schema columns and a
migration preview are visible, and the report shows grouped rows.
After integration, the merged provider and focused QML tests passed,
and the 1280×960 fixture screenshot was regenerated and inspected. Its
dump places `FormDesigner#formDesigner` at `0,0 628x228`.

Remaining: persistent form/report designs through `DocumentSession`,
multi-statement migration planning and rollback, richer report bands and
totals, paginated print/export, and saved-design qualification.
