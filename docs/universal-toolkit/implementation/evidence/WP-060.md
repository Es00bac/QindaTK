# WP-060 — Real audio engine and device settings

**State: active; package not accepted.** Audio I/O, session playback/record,
offline render, and device lifecycle are still unimplemented.

Luna's isolated `work/wp060-device-panel` lane was integrated as `6610b8b`.
`DeviceSettingsPanel` displays host-supplied devices and capabilities, keeps
the active configuration distinct from a pending choice, and emits requests
that only a host acknowledgment can accept or reject. The example host shows
both outcomes. It is a UI contract, not a device enumerator or audio engine.

The isolated Qt 6.11 QML acknowledgment test passed 3/3. Its fixture passed
`qtk-preview --check`; the dump placed the panel at 736×240 with active
48 kHz/256/Stereo and pending 96 kHz/128/Stereo-to-Quad. Sol inspected and
saved the [device panel screenshot](WP-060-device-settings.png). Merged-tree
QML compilation is queued with the other concurrent control lanes.
