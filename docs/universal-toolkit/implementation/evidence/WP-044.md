# WP-044 — Vector authoring and appearance

**State: active; package not accepted.** The WP-042 and WP-043 dependencies
are still active.

The integrated Luna lane (`1fb8eb7`) adds `StrokeStyleEditor`,
`FillStyleEditor`, `ShapePalette` and `AppearanceStack`. Their request contracts
keep full style/effect descriptors, including unsupported metadata. The
vector-authoring fixture applies requests to a small host-owned document; its
focused QML interaction check passed **3/3** on the merged Qt 6.11 tree and
`qtk-preview --check` passed.

Sol added `CanvasStyleModel` for the reference canvas. It applies solid fill,
stroke colour and width across selected visible, unlocked objects in one
undoable `CanvasEdit`; the canvas native codec preserves those fields. The
focused `tst_canvas_style_model` passed **1/1**, including two-object atomic
edit, undo, native save/reopen and locked-object rejection. The real
[style fixture](../../../../examples/vector-authoring/StyleWorkingScene.qml)
passed preview check; its dump placed `CanvasView#styleWorkingCanvas` at
`8,8 706x624`, `StrokeStyleEditor#styleWorkingStroke` at `0,0 390x237` and
`FillStyleEditor#styleWorkingFill` at `0,245 390x69`. Sol opened the
[1120×640 capture](WP-044-style-working.png); both objects and the inspector
are legible.

The merged Qt 6.8 build and focused `tst_canvas_style_model` CTest passed on
2026-09-23 with the configured `-j24 -l24` limits. The style fixture also
passed `qtk-preview --check` on that build.

Still required for the full package: persistent editable path geometry,
parametric shapes, dash/cap/join/alignment rendering, gradients and patterns,
appearance stack processing, selected-object property binding for all style
kinds, clipboard and a declared vector export path. The current reference
canvas explicitly rejects unsupported style properties.
