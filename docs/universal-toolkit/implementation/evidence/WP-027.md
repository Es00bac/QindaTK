# WP-027 — Virtual collections

**State: review.** Proposal scope: DAT-01 VirtualList, DAT-02 VirtualTree
and DAT-03 AssetGrid. Public properties and objectNames are in the
[control catalog](../../../controls.md#virtual-collections).

## Behavior delivered

- `VirtualCollectionAdapter` indexes stable IDs from a real
  `QAbstractItemModel`. A separate identity model preserves selection through
  proxy filter/sort/reset while source removals prune deleted identities.
  Source role IDs cannot collide with synthetic tree roles. Source lifetime
  is guarded, and nested insertion updates only the inserted subtree.
- `VirtualList` and `AssetGrid` recycle delegates. `VirtualTree` projects a
  hierarchical source into visible rows, fetches lazy children and retains a
  selected child's ID across collapse and reopen. Thumbnail subscriptions
  release when a tile is pooled and refresh on reuse. Reorder/rename are
  requests to the authoritative host model.

  38 tree and 13 grid delegates, not 240 of each. These are local run timings.
- The focused fixture covers role-key collision, model destruction, raw
  nested lazy expansion/collapse/reopen, surviving selection, source-removal

  including Ctrl-click and retained keyboard focus.
- The follow-up 100,000-asset fixture uses a generated `QAbstractListModel`
  directly in all three views and a real `AssetProvider` with a file-backed
  decoder and 64 KiB cache budget. It checks materialized delegates against
  the viewport, live subscriptions against grid tiles, decode queue and cache

  subscriptions, and zero subscriptions at teardown. Existing
  `tst_asset_provider` cases also hold backend completions past release and

  grid pointer modifiers, context requests, focus, arrow/Home/End/Enter;

## Follow-up isolated run

The fresh isolated build from integration `224a681` succeeded on Qt 6.11.1.
`tst_virtual_collection`, `tst_asset_provider`, and the QML runner passed.
The first scale test exposed a fixture-only error: it searched QObject
descendants for Qt Quick delegates, whose visual parent is the view's
`contentItem`. The corrected fixture passed and reported 39 list, 39 tree,
41 grid delegates at initial view, and 66 grid delegates after End navigation
across 100,000 rows. It observed at most four running and 34 queued decoder
jobs, and cache use of 5,511 and 42,251 bytes against a 65,536-byte budget.
These figures are single-machine observations; the assertions enforce bounds
instead of those exact counts. The 960×560 fixture polished to a 528×520
grid with a 524×516 viewport in 3,932 ms; End navigation took 29 ms. Its
[compact dark](../../../screenshots/asset-scale-compact.png) capture shows
decoded first tiles and pending placeholders, and its
[comfortable light](../../../screenshots/asset-scale-comfortable.png) capture
shows the final rows with decoded thumbnails. Both PNGs were inspected.
