# WP-003 — Layout, theme metrics and documentation drift

Status: **accepted** on the integrated source. This closes FIX-F05, FIX-F06
and DOC-01. The [F05 record](WP-003-F05.md) captures the layout conversion;
the [F06/DOC-01 checkpoint](WP-003-F06-DOC01.md) records the earlier partial
integration before the Ruler changes landed.

## F05 — Layout conversion

`KeyCap` and `Filmstrip` now use `Tk.Flex` instead of QtQuick `Row`.
KeyCap retains its implicit sizing through an outer `Item`; Filmstrip retains
frame count, positions, spacing, tail mapping and scroll behavior. The focused
QML test checks those contracts. At 640×360, `qtk-preview --dump` showed
the compact KeyCap row at 77×18 and three Filmstrip frames at x=0, 214 and
428, each 212×40; comfortable KeyCap was 85×22 and frames 212×48 at the
same x positions. Both density PNGs were opened. A corrected RGB comparison
against the baseline found 17 changed pixels at the last frame's far-right
border in each density, and no other changed region. This small raster edge
difference is retained in the evidence rather than described as identity.

## F06 — Derived chrome metrics

`TableColumn` defaults to `size.tableColumn` (80 compact) and `size.control`
minimum width (24). `Dialog` defaults to `size.dialogWidth` (420 compact)
and uses `size.border`. `Ruler` uses `size.rulerLength` (200 compact),
`size.rulerMarker` (9), `space.unit` minimum minor spacing, and theme roles
for its border, tick and cursor chrome. Tooltip delay, reading timeout,
border and opacity endpoints also use theme roles. Caller-specified data
dimensions remain caller owned.

The QML regression changed density at runtime and observed TableColumn
80/24→96/29, Dialog 420→504, Ruler marker 9→11, minimum minor spacing
4→5 and implicit length 200→240. The preview dump showed
`Ruler#metricRuler` at 400×22 compact and 400×26 comfortable, with marker
geometry 9×9 and 11×11. Both captures were opened. The TableColumn/Dialog
fixture showed the dialog at 420×94 compact and 504×109 comfortable;
both captures were opened with readable text and actions. A comfortable
large-text capture showed the dialog at 504×130 with its wrapped body and
actions still visible. These captures are fixture evidence, not a claim
about every possible host window.
