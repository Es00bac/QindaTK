# WP-032 / DAT-19 DiffView lane evidence

Source: isolated worktree based on `0086eba`, 2026-09-23, Linux offscreen
software renderer, Qt runtime 6.11.1, GCC 15.3.0, Debug/Ninja. Build used
`cmake -S . -B build/wp032-diff -G Ninja -DCMAKE_BUILD_TYPE=Debug` then plain
`cmake --build build/wp032-diff`; `portageq envvar MAKEOPTS` returned
`-j24 -l24`. No command-local job/load override was used.

## Behavior

- `tst_diff_model`: pass. Known-answer replacement, repeated/empty text,
  insertion/deletion alignment, bounded refusal, unchanged-revision guard,
  accept-one-hunk/recompute identity, canceled queued request, revision change
  cancel, provider destruction, and typed conflict/structured values.
- The 20,000-region synthetic `DiffPageProvider` is not materialized into a
  model vector. Reading one region made one `regionAt` call. Its `DiffView`
  created fewer than 50 visible `diffRegion` delegates at 800×360.
- Focused `tests/qml/tst_diff_view.qml`: 3 pass, 0 fail; navigation, preserved
  selected hunk after recompute, inline switch, and no-adapter request refusal.
- `example_diff-view` and `example_gallery`: pass. The example has no host
  adapter, so Accept/Reject are demonstrative request controls and cannot edit
  a source.

The built-in LCS is intentionally limited to 512 lines per side and rejects
larger snapshots with an error. Large/structured alignment is supplied by a
host `DiffPageProvider`, which must own stable hunk/conflict IDs and immutable
revision snapshots. A production document adapter is supplied by the host;
this lane tests the transaction boundary with an in-memory host adapter.
Integration and broader regression acceptance remain with Sol.
