# WP-004 — Catalog source inventory

Status: **accepted** on the integration branch after Sol review. This closes
[FIX-F07](../supporting-scope.md#fix-f07). Luna implemented the parser and
fixtures in worker commits `523eeac` and `3cf3e88`; Sol integrated them and
regenerated `docs/catalog.json` after the KeyCap/Filmstrip objectName update.

## Contract and result

`gen_catalog.py` parses repository QML files and selected C++ declarations.
It records `module`, `registrationKind`, `exported`, `anonymous`, `internal`,
`valueType` and `bridge` as **source declaration metadata**. These fields do
not assert that a compiled plugin exposes every declaration at runtime.
Inherited Qt APIs likewise are outside this inventory. The default output is
`docs/catalog.json`; `--output` writes an alternate path for comparison.

The checked-in catalog has 101 unique names: 78 main-module QML files, 21
previously recorded C++ entries, `stylusSample` and `QindaQtTheme`. No name
from the 99-entry starting catalog was lost. The 11 `StylusSample`
`Q_PROPERTY` declarations are recorded (10 MEMBER, one READ); the value type
and bridge have distinct registration provenance. Pointer properties now
include Theme group pointers and `GraphSeries.ramp`. Pointer returns include
`Graph.seriesAt`; multiline invokables include `DockModel.registerPanel`.
The converted KeyCap and Filmstrip row objectNames are included.

## Verification

- `python3 -B tools/scripts/test_gen_catalog.py`: passed before and after
  regeneration. Fixtures cover value, anonymous and bridge declarations,
  pointer properties/returns, MEMBER semantics and multiline invokables.
- Two independent `--output` generations matched byte-for-byte, and matched
  the checked-in `docs/catalog.json` via `cmp`.
- JSON comparison against the previous checked-in catalog: 99 prior names
  preserved, only `stylusSample` and `QindaQtTheme` added. Theme properties
  rose from 5 to 13, GraphSeries from 11 to 12, Graph methods from 5 to 6,
  and DockModel methods from 39 to 42 because the previous source parser
  missed declarations.
- `git diff --check` passed for the integrated change.

No visual, editing, scale or runtime-backend gate applies to a source catalog
generator. The result is intentionally not claimed as compiled API reflection;
WP-005 and final SDK qualification retain compiled-consumer checks.
