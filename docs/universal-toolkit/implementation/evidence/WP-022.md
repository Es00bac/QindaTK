# WP-022 — Reusable typed inspectors

**State: accepted at integration revision `224a681`.** Proposal scope: CTL-12 Inspector, CTL-13
MixedValueField, CTL-14 UnitField, CTL-16 VectorField, CTL-17
TransformEditor and CTL-24 FormGroup. APIs and objectNames are in
[controls](../../../controls.md#command-composition-and-typed-inspectors).

## Behavior delivered

- Schema rows select numeric, vector or text editor delegates. A common
  wrapper exposes mixed, unset, validation, read-only and reset states;
  FormGroup reports pending/invalid fields and focuses the first invalid one.
- UnitField keeps canonical values separate from display-unit scale/offset
  and commits through `PropertyBinding`. VectorField calls the C++
  `updateComponent` patch operation, which validates each target's whole
  vector while preserving its untouched axes under mixed multi-selection.
  One gesture creates one undo step. TransformEditor composes separately
  bound position, rotation, scale and pivot fields; domain matrix
  decomposition remains with a host adapter.

  fixture passed, including 10/10 QML cases through a test-only C++ document

  6.11 and Qt 6.8 consumers imported `Inspector` from staged packages.

## Boundaries

The reference vector component patch supports QVector2D/3D/4D and finite
2–4-element QVariantLists. Hosts provide geometry/matrix decomposition and
unit metadata. Inspector descriptors carry already configured bindings;
authoritative values stay in the document, not in QML delegates.
