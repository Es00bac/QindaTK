## Focused scenes recommended

1. **Section disclosure:** instantiate `SectionHeader` and `PropertyGroup` with focus sentinels before/after; verify Tab/Shift+Tab, Space/Return, pointer toggle, `Accessible` role/name/expanded state/action, disabled/noncollapsible behavior, and a bound `collapsed` source remains synchronized after interaction.
2. **Time ruler:** make caller-owned origin/scale/value spies; verify Tab focus, Left/Right and Home/End (defined range), Space/assistive action through the same scrub operation as pointer/drag, Accessible value/range/name, clamping, disabled state, and that external playhead/origin updates do not emit user `scrubbed` notifications.
3. **Input state contract grid:** for CheckBox (unchecked/checked/partially checked), RadioButton, Switch, Slider, RangeSlider, NumberField, TextField/TextArea, ComboBox and ColorField, drive user and programmatic changes separately; assert default/reset, mixed where supported, invalid input/error recovery, read-only/disabled edits, focus traversal, accessible action/state/value, and emitted user-only signals. Include min/max/step and reversed/equal range boundaries.
4. **Selection and popup scene:** compare pointer, keyboard and accessible activation for Segmented/PillSwitcher/TabStrip, including selection removal/reorder/disabled entries; open nested Menu, Dialog, Popover and CommandPalette in a constrained window, then assert focus entry/return, Escape cancellation, reachable bounds, and no duplicate activation.
