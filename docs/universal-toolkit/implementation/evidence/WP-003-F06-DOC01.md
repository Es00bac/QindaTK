# WP-003 / F06 and DOC-01 — token and documentation repair

Status: **partial**. The TableColumn and Dialog chrome defaults now read
theme size roles, and the audited documentation drift outside the private Qt
boundary has been corrected. Ruler marker use of its new role awaits the
independent F02 worker integration. The private Qt documentation is held for
WP-005's chosen boundary. WP-003 is not yet accepted.

## Source changes and scope decision

- `size.tableColumn` is 80 at compact density; `TableColumn.width` uses it.
  `minWidth` uses existing `size.control` (24). Caller-provided column widths
  remain document/data dimensions and are not rewritten.
- `size.dialogWidth` is 420 at compact density; `Dialog.dialogWidth` uses it.
  The dialog still clamps to its host, and its 1 px chrome borders now use
  `size.border`.
- `size.rulerMarker` is 9 at compact density. The role is installed before
  changing Ruler because F02 owns that source file concurrently.
- The theme size table now lists the existing media metrics. Tooltip's source
  comment and the controls convention now say to instantiate a child
  `Tk.ToolTip`. Its 600 ms delay, 6000 ms reading timeout, borders and opacity
  endpoints now use theme roles. Reduced motion removes the delay but retains
  the reading timeout. The media reference has a stable index link. The Graph
  header describes both geometry and software-raster rendering paths.
- The verification guide now lists stylus, app-window and telemetry tests and
  states the user's direct-build job/load policy accurately.
