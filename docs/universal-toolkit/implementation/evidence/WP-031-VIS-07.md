# WP-031 VIS-07 uncertainty lane evidence

**State:** focused VIS-07 lane complete; WP-031 remains active. Integrated
package verification and other visualization families are separate gates.

## Delivered contract

- `UncertaintyModel` accepts up to 100,000 ordered source intervals with
  stable interval and source IDs. It retains declared `Confidence`,
  `Credible`, or `Domain` meaning, coverage or domain detail, dataset ID,
  and X/Y units. Reversed, one-sided missing, duplicate, nonfinite and
  unsorted input is rejected atomically. Missing intervals keep their
  estimates and identity; signed endpoints remain signed.
- `UncertaintyRenderer` uses matching numeric `ChartAxis` domains to draw
  point error bars or continuous bands. Missing intervals break a band and
  use a distinct marker. Normalized viewport access uses binary X lookup;
  visible drawing is sampled to a bounded count. Hit testing, keyboard
  navigation, and selection use stable IDs.
- `UncertaintyView` provides a themed surface, accessible meaning and
  selection summary, and a virtual table with exact endpoints, status,
  source IDs and meaning. CSV includes every source row. PNG and SVG use the
  screen painter and embed complete `QindaTK.uncertainty.v1` JSON metadata.

## Focused verification

The isolated worktree was based on `58f18c7`. `build/wp031-uncertainty`
used Qt 6.11.1. The configured system `MAKEOPTS` remained `-j24 -l24`;
the full and final incremental builds used plain `cmake --build` and exited
zero.

- `ctest -R '^(tst_uncertainty|example_uncertainty)$'` passed 2/2.
  The C++ fixture checked exact projected coordinates (X 50px, estimate
  50px, low 70px, high 30px), hit/selection identity, a blue known band
  pixel, a white gap pixel, PNG and rasterized SVG pixels, and matching
  embedded JSON metadata with source IDs and coverage.
- The C++ fixture also exercised Credible, Confidence, and Domain meanings;
  missing, reversed, one-sided and nonfinite endpoints; atomic rejection;
  a 10,000-row source with at most 64 drawn marks; a narrow viewport;
  selection retention; and the 8192px output bound.
- The focused QML file passed 3/3 cases for typed rows, selection,
  mode switch, zoom, CSV and visible table alternative. The example
  instantiated under CTest.
- At compact dark density, `UncertaintyView#uncertaintyView` measured
  `8,32 944x298` and `8,334 944x298`. At comfortable light density,
  it measured `10,35 940x295` and `10,335 940x295`. The two grabs were
  opened and inspected: the top plot shows distinct whiskers and missing
  marker; the lower plot shows a band interrupted at the missing hour,
  axis ticks, meaning, units and missing count. See
  [compact](../../../screenshots/uncertainty-compact.png) and
  [comfortable](../../../screenshots/uncertainty-comfortable.png).

The adapter currently supports numeric and logarithmic axes. Category and
DateTime axes require a typed X input extension; host statistical engines
remain responsible for producing interval endpoints and coverage.
