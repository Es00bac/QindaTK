# WP-028 — Editable two-dimensional grid

**State: active.** Proposal scope: DAT-04 EditableGrid, DAT-05 HeaderView and
DAT-06 RangeSelectionOverlay. The Sol C++ foundation is committed as
`ee36103` in isolated branch `work/wp028-grid-core`. A separate Luna lane is
building the QML grid, headers and range overlay. The package is not accepted.

## Foundation delivered and measured

- `EditableGridModel` derives from `QAbstractTableModel` and retains stable
  row/column IDs through reorder. It stores sparse overrides over a lazy
  `GridCellSource`, returns bounded visible windows, computes frozen-region
  geometry and stores selections by endpoint ID.
- Validated cell edit, paste and fill are atomic transactions. Local undo is
  available; an explicit external history bridge checks transaction identity,
  revision, structure generation, payload and current cell values. Theme
  density can set default row/column sizes without per-section calls.
- Isolated focused CTest passed **1/1** (six substantive QtTest cases).
  The 100,000 × 100 fixture set dimensions in **188 ms**, read exactly
  **640** source cells for a 32 × 20 viewport and none during setup, and
  held no sparse overrides before editing. The Qt test process peak RSS was
  **73,360 KiB**. These are local measurements, not cross-platform budgets.

## Visual layer delivered and checked

Commit `05f7738` adds `EditableGrid`, `HeaderView`, `RangeSelectionOverlay`,
a 100,000 × 36 example and focused QML fixture. Its isolated full build,
focused QML **5/5**, C++ grid **6/6** and `all_qmllint` passed. The worker
inspected compact and comfortable captures. At 1096×588, the grid shows a
1016×24 column header, 80×564 row header and 1016×564 clipped cell viewport;
  338 visible delegates represent the 100,000-row model. Root also opened both
  captures and checked the frozen/header alignment and selection outline.
Drag resize/reorder,
frozen range splits and committing a draft to its original cell after focus
moves are exercised. Full paths and remaining host seams are in
[visual-lane evidence](WP-028-visual.md).
The integrated Qt 6.11 focused grid QML suite also passed **5/5** after the
QML source was added to the shared module.

identity; synchronized frozen headers; validated edit/paste/fill as one undo
transaction; keyboard and accessible range navigation; and installed consumer

smaller substituted workload.
