# WP-043 — Document color and curve editing

**State: active presentation slices; package not accepted.** Its WP-040
dependency and color/curve backend work remain open.

`Tk.CurveEditor` is a reusable host-data curve surface. The host supplies
stable-ID normalized knots and an already evaluated sample line. The control
maps those values to view coordinates and reports knot selection, move
preview, finish and cancel through pointer, keyboard and accessible actions.
A click selects without committing. Pointer ownership stays on the editor
root, so replacing the host knot array during a preview does not lose the
gesture. The host owns canonical interpolation, constraints, transactions,
undo and persistence.

The focused QML suite passed **4/4** on Qt 6.11.1 and Qt 6.8.3. It checks
normalized/view mapping, stable ID requests, cancel without mutation, a
selection click without finish, and a drag that finishes after the host
replaces knot records. The scene passed `qtk-preview --check` on both Qt
versions. The compact dump showed `CurveEditor#curveSceneEditor 12,54
876x534`, `CanvasItem#curvePlot 10,10 856x514`, and four 20×20 hit targets
`curveKnot_black`, `curveKnot_shadow`, `curveKnot_midtone`,
`curveKnot_white`. Sol opened the
[compact](WP-043-curve-compact.png) and
[comfortable](WP-043-curve-comfortable.png) 900×600 captures; the supplied
cyan sample line and all four knots remain inside the plot at both densities.
The reproducible scene is
[CurveEditorScene.qml](../../../../examples/spatial-canvas/CurveEditorScene.qml).
After integration, the full Qt 6.11.1 and Qt 6.8.3 CTest suites each passed
**102/102**.

`Tk.GradientEditor` presents host-owned stable-ID color stops. It requests
selection, insertion, preview, finish, cancel and deletion; the host owns
canonical order, values, transactions and undo. The live stop preview follows
the pointer, keyboard and accessible increase/decrease actions nudge by a
configurable normalized step, and a drag returned to its starting value
emits cancel. Focused Qt 6.11 QML tests passed **9/9**, covering those
interactions and host record replacement during a drag. The preview dump
places `GradientEditor#gradientEditor 12,12 876x40`,
`CanvasItem#gradientPreview 1,1 850x16` and three stable stop targets.
The same focused **9/9** QML suite passed on Qt 6.8.3. Sol opened the
[compact](WP-043-gradient-compact.png) and
[comfortable](WP-043-gradient-comfortable.png) captures; the preview and
three colored stops render at both densities. The fixture is
[Main.qml](../../../../examples/gradient-editor/Main.qml).
The shared Qt 6.11 and Qt 6.8 CTest suites each passed **104/104** after
the gradient integration.
`all_qmllint` exited 0 with existing warnings outside this control; the
catalog generator and preservation fixtures passed at 264 types.

**Still required:** typed curve domains and precision, interpolation and
extrapolation semantics, tangents and multi-knot edits, constraints, an
authoritative transaction/undo/persistence path, color profiles and transforms,
stop interpolation and picker controls, and numerical plus software/GPU output
fixtures.
