# WP-021 — Document and application navigation

**State: review.** Proposal scope: CTL-04 Ribbon, CTL-07 DocumentTabs,
CTL-08 NavigationRail and CTL-09 BreadcrumbBar. Public properties and
stable objectNames are in [controls](../../../controls.md#application-and-document-navigation).

## Behavior delivered

- Ribbon filters contextual tabs by host context, binds command items through
  `CommandRegistry`, offers key tips and collapses or scrolls narrow groups.
- DocumentTabs projects real `DocumentManager` sessions and its authoritative
  `viewOrder`. View activation and reorder call the manager. Closing one of
  several views leaves the document open; a dirty last view requests a host
  decision, and a blocked close clears its pending state.
- NavigationRail presents host-owned route groups, omits hidden/disallowed
  entries and preserves stable destinations. BreadcrumbBar navigates by ID,
  provides a sibling menu and scrolls a long path.

## Route and sibling-provider follow-up

- `NavigationRail.activate()` emits a destination request without changing
  `currentId`. The host calls `confirmRoute(id)` after accepting navigation.
  A hidden, disabled, removed or invalid restored ID resolves to the first
  enabled visible route, or empty if none exists. `routeReconciled` lets the
  host update its persisted route. Stale entry objects cannot request routes.
- A breadcrumb segment with `siblingProvider: true` now displays a sibling
  button without an inline list. `siblingsRequested(id,requestId)` allows an
  asynchronous host fetch; `supplySiblings(id,requestId,items)` opens the menu
  only for the current request. Replaced paths and stale replies cannot open
  a menu against a recycled segment.
- The named `build/wp021-nav` Qt 6.11 `tst_qml` target and `qtk-preview` target
  linked successfully with plain `cmake --build`, using configured system
  parallelism. The focused navigation QML fixture passed **9/9**, including
  host refusal, valid route restoration/removal, request-token rollover,
  delayed sibling delivery and stale-result rejection.
- Compact and comfortable 720×320 previews were dumped, grabbed and opened.
  The provider-backed folder chevron is visible in both. Compact dump:
  `NavigationRail 12,12 200x296`,
  `BreadcrumbBar 0,23 302x24`,
  `IconButton#breadcrumbSiblings_folder 100,0 24x24`.

## Acceptance still open

The literal style sizes/colours in Ribbon and NavigationRail were repaired
in the integrated source. Dual-Qt and installed-consumer checks against the
follow-up remain open. The application owns
route persistence and dirty-close policy; the controls do not store document
content or silently discard a dirty session.
