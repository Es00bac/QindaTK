# WP-015 — Asynchronous jobs and asset services

**State: accepted.** This package implements APP-13 JobModel, APP-14
AssetProvider and APP-19 ResourceResolver. The public contract and limits are
in [jobs, assets and resource links](../../../assets-jobs.md); the document
history boundary is [D-032](../../../decisions-services.md#d-032--document-uri-history-and-runtime-resource-projection).

## Behavior delivered

- `JobModel` schedules copied worker callables through a bounded Qt thread
  pool, with priority/FIFO dispatch, cooperative cancellation, progress,
  inspectable results and retained terminal rows. Document revision/reset and
  view generation checks reject late results after an edit, close or recycled
  delegate. Workers do not read live QObject state.
- `ResourceResolver` owns stable logical IDs, URI, expected/observed SHA-256,
  revision and missing/ready/modified availability. Cached lookup avoids I/O.
  Async refresh and exact-hash batch proposals run through `JobModel` with
  cancellation and stale-mapping checks. A committed mapping can be restored
  to a missing local URI during undo without losing the expected hash.
- `DocumentResourceLinks` stores a resource manifest in `PropertyDocument`:
  an external relink validates one destination and commits one undoable URI
  edit. Multiple clips retain the same logical ID, so relink/undo/redo change
  every reference without copying paths or changing clip timing. Closing,
  destroying or switching documents retires the adapter's mappings.
- `AssetProvider` coalesces equal in-flight requests, returns stable
  subscriptions, bounds its LRU cache, cancels orphaned work and invalidates
  both loading and already-ready subscriptions after a resource, backend,
  document or view change. The file backend extracts metadata, scaled PNG
  thumbnails and integer-PCM WAV peaks. Unsupported video requests report a
  visible failure. `AssetThumbnail`, `AssetWaveform` and `AssetFilmstrip` own
  and release subscriptions in QML.

## Boundaries

The default backend supports local image thumbnails and integer-PCM RIFF/WAV
peaks. Video decoding, remote assets, domain-specific resource persistence,
and very large media use replaceable backends or later packages, including
WP-070 for video. Cancellation is cooperative: an uncooperative backend may
delay completion of its worker slot. Synchronous registration and validated
relink hash local files; interactive large-file refresh and batch search have
the async API. QML adapters display provider state but do not invent media
data when a backend reports unsupported input.
