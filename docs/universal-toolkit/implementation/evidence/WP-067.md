# WP-067 — Score and notation editing

**State: active; package not accepted.**

Luna's `work/wp067-scoreview` lane was integrated as `dc7012f`. `ScoreView`
draws a bounded host-supplied notation snapshot and emits note/rest insertion,
selection and navigation requests. Stable event IDs and host-discrete exact
ticks carry editing intent. Unsupported features remain visible rather than
being drawn as valid music notation.

The isolated Qt 6.11 configured-limit build, two focused QML cases and
preview check passed. The merged focused run passed 4/4 including setup and
cleanup, and `example_score-view` passed. The merged dump placed
`ScoreView#scoreView` and `CanvasItem#scoreCanvas` at 1096×558. I opened and
inspected the [merged score fixture](WP-067-score-view.png).
Engraving/layout, rhythmic validation, persistent edits, interchange,
audition and playback remain backend work.

## Code-first round cf1: notation backend (work/wp067-cf)

Built on the WP-064 MIDI model and scheduling and the WP-049 tempo map;
documented in [notation.md](../../../notation.md), decisions D-178 to D-181.
Tests below are written, not yet run (the round build runs them).

1. **Score objects, voices, ties, tuplets, spelling, articulations, parts,
   MIDI/musical time** — built. `ScoreModel` (D-178): UUID score, measures
   (meter, key, breaks), parts (channel, 1–4 staves), staves (clef, voices
   1–4), events (rest or chord) and notes (spelled pitch, tie); note values
   with dots and any tuplet ratio exact at 960 PPQ; six articulations and
   eight dynamics; whole-content validation. Linkage to MIDI and musical
   time is `Score::toMidi` and `ScorePlayback` (D-180). Tests:
   `tst_score_model`.
2. **Functional layout backend, dense multi-voice measures, page breaks** —
   built. `Score::layoutScore` (D-179): shared time columns, proportional
   spacing, accidentals in key/measure/tie context, stems by voice, beams by
   beat with secondary beams, ties across systems, tuplet brackets, system
   and page breaking with forced breaks, justification, part extraction.
   ScoreView draws its snapshot (ScorePaint.js). Tests: `tst_score_layout`
   (dense two-voice measure, 240-measure pagination, breaks, justification).
3. **Note/rest/rhythm entry, selection, notation edits through a persistent
   model** — built. Overwrite entry with aligned rest filling and tuplet
   groups; `editEvent` (duration, dot, tie, articulation, dynamic, pitch,
   step, transpose, respell, chord notes, rest), delete, voices, measures,
   meters, keys, breaks; every change one undo step; native
   `qindatk.score/1` file. ScoreView gained `notationEditRequested`,
   `eventDeleteRequested`, editing keys and the selected event's spoken
   label; each request maps to one model call. Tests: `tst_score_model`,
   `tst_score_edit.qml`.
4. **Playback/audition, print/page output, declared interchange, expressive
   data outside MIDI** — built. `ScorePlayback` syncs the score into one
   `session.midi` pattern and a beat-locked clip (stable UUIDv5 note IDs,
   tie chains merged, staccato and dynamics mapped), maps the transport to
   the score cursor and auditions chords on the engine's cue voices;
   spelling, voices, tuplets and articulation symbols stay in the score
   (`retained`). PDF pages and images from the same layout. MusicXML 4.0
   partwise export and import (D-181) with IDs in `id` attributes and
   processing instructions and a report of unsupported content. Tests:
   `tst_score_interchange`, `tst_score_layout` (PDF, image pixels). Scope:
   printing to a printer device goes through the WP-053 print backend with
   the PDF; output-fidelity comparison with other notation programs is
   WP-088…WP-094.
5. **Verification: rhythmic totals, ties/tuplets, accidental context,
   pagination, undo, native/interchange round trip** — covered by
   `tst_score_model` (totals, tuplet groups, ties, accidentals, undo, native
   round trip), `tst_score_layout` (pagination), `tst_score_interchange`
   (MusicXML round trip with every ID, foreign-file report, MIDI conversion
   and session playback at exact samples through a tempo change), not yet
   run. Scope: performance measurement, other platforms, screen-reader runs
   and translation are WP-088…WP-094; grace notes, slurs, lyrics, repeats,
   chord symbols, clef changes and transposing instruments are declared
   unsupported (`capabilities.unsupported`) and reported on import.
