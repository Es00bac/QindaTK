# WP-058 — Mail, calendars and task workflows

**State: active; package not accepted.**

Luna's `work/wp058-productivity-controls` commit `cd3351a` supplied
`MailView`, `RichMailComposer`, `CalendarView`, `RecurrenceEditor` and
`TaskBoard` with a gallery section and combined fixture. They consume host
snapshots and send correlated edit requests. The fixture blocks delivery,
does not persist draft acknowledgments, and supplies recurrence previews
through a mock host in the original fixture.

The isolated build inherited configured `MAKEOPTS=-j24 -l24`; focused QML
checks passed 3/3, and both the suite fixture and gallery instantiated. The
merged Qt 6.11 build, focused QML test (3/3), example smoke and catalog check
passed. The merged dump places `MailView#mailView` at `0,0 628x281` with
CalendarView, TaskBoard and RecurrenceEditor visible below. The
[1280×900 screenshot](WP-058-productivity.png) was opened and inspected.

`RecurrenceService` now expands daily, weekly, monthly and yearly local-wall
rules with intervals, weekly weekdays, count/until ends and exceptions. It
skips nonexistent spring-forward times and chooses the earlier offset in a
fall-back fold. The merged focused C++ test passed, including a Denver DST
transition and an excluded occurrence. The productivity fixture now obtains
its preview from this service; the [1160×900 recurrence screenshot](WP-058-recurrence.png)
was opened and inspected and shows five locally computed rows after one
exception.

`LocalProductivityStore` now persists the four collections as a versioned
snapshot with stable IDs. It uses atomic replacement and retains the previous
valid snapshot for recovery after primary-file corruption. Task moves compact
ordering and have local undo. The `examples/local-productivity` fixture
connects message actions, draft saves, calendar acknowledgments, and task
move/undo to this store. The isolated configured-limit build, focused 3/3
store tests and fixture check passed; merged validation is recorded below.
The merged build passed with configured `-j24 -l24`; the focused C++ test
passed 3/3. The [1440×980 local-store screenshot](WP-058-local-productivity.png)
was opened and inspected. Its dump places `Caption#localStoreStatus` at
`8,45 1424x13` and the four panels in a 1424×910 grid.

The store now applies and undoes local calendar shifts, rejecting DST gaps and
folds, and the fixture persists and acknowledges accepted move requests.

`LocalAttachmentStore` now saves and rereads actual local attachment payload
bytes by stable ID (8 MiB bound), separately from draft metadata. It stages
metadata and bytes together and rolls back a failed replacement. The isolated
configured-limit build, focused 3/3 byte test and fixture check passed; its
900×560 screenshot was inspected. Merged validation follows.

Remaining: provider adapters for real delivery/sync and attachment upload,
recurrence expansion in saved events, and rich composer formatting. Task
ordering still needs a multi-writer conflict policy before remote sync.
