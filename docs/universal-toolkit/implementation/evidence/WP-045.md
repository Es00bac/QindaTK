# WP-045 — Raster, masks, brushes and comparison

**State: active; package not accepted.**

The `CompareView` control and `ImageCompareItem` render two equal-size images
with split, blink and absolute encoded-sRGB difference modes. They share a
single zoom and pan transform. Images with mismatched dimensions, failed
loads or more than 16 million pixels are rejected. The control accepts local
image URLs; hosts can also pass `QImage` values to the C++ renderer.

The configured-limit integration build passed. `tst_image_compare_item`
passed with pixel checks for all three modes and a mismatched-image case.
The [1100×760 fixture screenshot](WP-045-image-compare.png) was opened and
inspected. Its dump places `CompareView#compareFixture` at `8,75 1084x677`,
with `ImageCompareItem#compareImage` at `0,0 1068x596` inside its viewport.

The item now also reads bounded PNG data URLs, allowing a live
`TiledRasterDocument.imageDataUrl` to drive a comparison view. The focused
comparison test passed for a pair of live data URLs.
The QML control now owns split-divider drag, blink press/release, wheel zoom,
and middle-button pan gestures. Its focused QML file passed 3/3 checks in the
merged tree.

`TiledRasterDocument` now paints premultiplied RGBA across 256 px tiles with
stable layer IDs, sparse 8-bit masks, deterministic pressure/tilt/hardness
sampling, one transaction per stroke, bounded undo/redo and atomic composite
PNG export. The merged configured-limit build and focused raster test passed.
The [1080×680 raster screenshot](WP-045-tiled-raster.png) was opened and
inspected: a stroke crosses a tile seam and a mask removes its center.

`MaskChannelPanel`, `BrushPresetView` and `BrushDynamicsEditor` now expose
stable host snapshots and explicit request/acknowledgment contracts. The
focused QML file passed 5/5 checks. Its
[1180×760 controls screenshot](WP-045-mask-brush-controls.png) was opened and
inspected. The [1200×850 combined workbench screenshot](WP-045-raster-workbench.png)
was also opened and inspected: the actual raster pixels and synchronized
comparison are visible alongside live mask and brush controls. The combined
fixture sends mouse strokes to the tiled document and maps control requests to
its supported actions.

The raster document now saves and reopens a versioned atomic state containing
tile pixels, sparse mask coverage, stable layer IDs and the brush preset. Its
composite image and PNG output carry an sRGB tag. The merged configured-limit
build and focused raster test passed. The
[1080×680 persistence screenshot](WP-045-raster-persistence.png) was opened and
inspected; the dump shows the `Save State` and `Reopen` actions and a painted,
masked stroke with the saved document status visible.

`RasterStrokeInput` now maps target-local tablet or mouse coordinates into
raster pixels and sends pressure and tilt samples to the document. One gesture
commits one stroke; Escape, lost grab, disable, or context replacement cancels
the in-flight stroke. The merged configured-limit build and focused synthetic
tablet/mouse/Escape test passed. The
[1080×680 input screenshot](WP-045-raster-stroke-input.png) was opened and
inspected; the dump places `RasterStrokeInput#rasterStrokeInput` at
`0,0 640x320` over the painted canvas. Actual tablet fidelity depends on the
Qt platform plugin and device driver; eraser input currently uses the
configured paint color.

Remaining: CanvasDocument/CanvasSurface session integration, broader color-management
work beyond the current sRGB tag, and combined graphics qualification.
