# WP-084 — Geographic mapping

**State: active; package not accepted.** The integrated local vector map has
explicit WGS84/WebMercator coordinates, stable feature identity, GeoJSON
round-trip and rendered selection/navigation. This lane adds a local XYZ tile
source, asynchronous visible-tile decoding, stale-result rejection, a bounded
decoded cache, raster/vector composition, missing-tile status and attribution.
The example uses 25 generated local PNG tiles without a network dependency.

Focused verification in `build/wp084-raster`:

- `ctest -R '^tst_geographic_(map|tiles)$'`: 2/2 passed. The tile test covers
  manifest import, off-thread decode, stale request rejection, cache limit,
  missing status and paint composition.
- Follow-on network slice: `ctest -R '^tst_geographic_tiles$'` passed after
  adding the local HTTP fixture. It holds one tile response while the visible
  set changes, confirms the stale reply is discarded, loads the next tile,
  verifies the bounded disk cache, and confirms a second source serves that
  tile from cache without another HTTP hit. The offline geographic example
  still passes `qtk-preview --check`; no example layout changed.
- Vector editing slice: `ctest -R '^tst_geographic_(map|tiles)$'` passed 2/2
  after both runners were rebuilt. The edit test adds a point, line and
  polygon; moves the point by API and pointer drag; translates the line;
  rejects invalid polygon replacement without changing it; clears selection
  on deletion; saves, exports and reopens while checking stable IDs,
  coordinates, properties and attribution. The example passes
  `qtk-preview --check` with no visual layout change.
- `qtk-preview examples/geographic-map/Main.qml --density compact --wait 1500
  --dump --grab docs/screenshots/geographic-map.png --size 960x640`: opened and
  inspected. `MapView#fixtureMap` is `944x581`; `mapTileStatus` shows
  `15/15 ready, 0 missing, 0 failed`.
- The same preview at comfortable density was opened and inspected in
  [geographic-map-comfortable.png](../../../screenshots/geographic-map-comfortable.png).
  `MapView#fixtureMap` is `940x575`, and the tile status is also `15/15 ready`.
  Both captures visibly layer the route, district and selected point over
  illustrated tiles, with both attributions at the bottom.

Multiple tile providers, general CRS support, vector spatial indexing, vertex
handles and a composed raster/vector image export remain open WP-084 work.
