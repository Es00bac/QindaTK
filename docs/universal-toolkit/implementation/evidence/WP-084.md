# WP-084 — Geographic mapping

**State: accepted for the documented WGS84/GeoJSON and two display projections.** The integrated local vector map has
explicit WGS84/WebMercator coordinates, stable feature identity, GeoJSON
round-trip and rendered selection/navigation. This lane adds a local XYZ tile
source, asynchronous visible-tile decoding, stale-result rejection, a bounded
decoded cache, raster/vector composition, missing-tile status and attribution.
The example uses 25 generated local PNG tiles without a network dependency.

Focused verification in `build/wp084-raster`:

- `ctest -R '^tst_geographic_(map|tiles)$'`: 2/2 passed. The tile test covers
  manifest import, off-thread decode, stale request rejection, cache limit,
  missing status and paint composition.
- Follow-on network slice: `ctest -R '^tst_geographic_tiles$'` passed after
  adding the local HTTP fixture. It holds one tile response while the visible
  set changes, confirms the stale reply is discarded, loads the next tile,
  verifies the bounded disk cache, and confirms a second source serves that
  tile from cache without another HTTP hit. The offline geographic example
  still passes `qtk-preview --check`; no example layout changed.
- Vector editing slice: `ctest -R '^tst_geographic_(map|tiles)$'` passed 2/2
  after both runners were rebuilt. The edit test adds a point, line and
  polygon; moves the point by API and pointer drag; translates the line;
  rejects invalid polygon replacement without changing it; clears selection
  on deletion; saves, exports and reopens while checking stable IDs,
  coordinates, properties and attribution. The example passes
  `qtk-preview --check` with no visual layout change.
- Projection/export slice: the same focused CTest selection passes 2/2.
  Known-coordinate checks cover the Web Mercator latitude limit, the
  antimeridian line hit and wrapped XYZ X coordinates. The PNG test samples
  distinct colors on both sides of the seam and the vector point at the
  declared viewport, confirms combined attribution/CRS metadata and verifies
  the live camera did not move. `qtk-preview /tmp/wp084-map-export.qml --check
  --wait 300` exported the example's local source at 960×640; I opened and
  inspected [the composed PNG](../../../screenshots/geographic-map-export.png).
- Projection/index slice: the focused geographic CTests pass 2/2 after the
  index was corrected to include shortest-path antimeridian segments at the
  seam. The known-coordinate test switches the same camera between Mercator
  and equirectangular, checks exact equirectangular pixel Y for 45°N, inverse
  picking, CRS fields and pole behavior. A generated 10,000 point GeoJSON
  fixture yields one local candidate; picking works under both projections,
  and moving the point invalidates/rebuilds the index. With a local tile
  manifest and equirectangular display, `tileStatus` reports incompatibility
  and export rejects tile composition. The preview dump shows the status,
  selection and inspector; I opened and inspected the
  [equirectangular screenshot](../../../screenshots/geographic-map-equirectangular.png).
- `qtk-preview examples/geographic-map/Main.qml --density compact --wait 1500
  --dump --grab docs/screenshots/geographic-map.png --size 960x640`: opened and
  inspected. `MapView#fixtureMap` is `944x581`; `mapTileStatus` shows
  `15/15 ready, 0 missing, 0 failed`.
- The same preview at comfortable density was opened and inspected in
  [geographic-map-comfortable.png](../../../screenshots/geographic-map-comfortable.png).
  `MapView#fixtureMap` is `940x575`, and the tile status is also `15/15 ready`.
  Both captures visibly layer the route, district and selected point over
  illustrated tiles, with both attributions at the bottom.

Additional tile providers, general CRS transforms beyond EPSG:3857/4326 and
vertex handles remain outside the documented supported operation set.

The shared integration tree built the map and CAD targets and passed the
focused geographic map/tile suites **2/2**. Sol opened the merged local,
composed-export and equirectangular captures. The declared WP-043 color
dependency subsequently passed its merged color/output gate. The shared
Qt 6.11 `tst_geographic_map` and `tst_geographic_tiles` targets passed **2/2**
again alongside that gate. Known-coordinate projection switching, indexed
picking, offline/stale tile status, editing and GeoJSON/PNG output meet the
WP-084 completion check. WP-084 is accepted for those capabilities; no
general-purpose GIS projection library or editable vertex-handle claim is made.
