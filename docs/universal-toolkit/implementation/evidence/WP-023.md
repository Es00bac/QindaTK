# WP-023 — Expression, path and token editors

**State: accepted.** Proposal scope: CTL-15 ExpressionField, CTL-20
FilePathField and CTL-21 TokenField. Public controls are in
[controls](../../../controls.md#command-composition-and-typed-inspectors).

## Behavior delivered

- `ExpressionEvaluator` accepts arithmetic, parentheses, unary signs, exact
  scoped identifiers, dimensioned units and `abs`/`min`/`max`/`clamp`. It
  rejects arbitrary code and bounds input to 512 UTF-16 units, 128 tokens,
  16 nested calls/parentheses and 256 operations. ExpressionField previews
  a canonical value and commits through its property binding.
- `UriValidator` checks local file URLs asynchronously and preserves remote
  availability as unknown. FilePathField checks request, draft and document
  revisions before accepting validation or a native browse result.
- `TokenEditorService` creates stable UUID token identities, parses bounded
  paste input and commits typed `QVariantList` values transactionally.
  TokenField handles duplicate policy, removal, reorder, completion and
  stale-result/IME guards.

## Verification

- Worker commit `9a06291` contains the evaluator, URI and token services,
  three controls, focused C++ test and QML test. The isolated Qt 6.11 C++
  test passed real token transaction/undo, stale completion and native
  FileDialogAdapter cancel/stale/remote-URI commit/undo scenarios. The focused
  QML suite passed 5/5.
- The worker rendered and inspected a preview. `expressionInput` is 776×24,
  `pathInput` 724×24 and `tokenInput` 645×24; the last holds two 28px chips
  and a visible invalid-token indicator.
- The shared Qt 6.11 suite passed **68/68**. The first Qt 6.8 suite found a
  version-specific browse failure: QML converted a selected `QUrl` to decoded
  text, turning `%20` into a raw space rejected by strict URI validation.
  `FileDialogAdapter` now supplies `encodedUrls` from `QUrl::FullyEncoded` and
  `FilePathField` commits that string. The focused expression/browse test and
  bounded-editor/format-dialog QML suites then passed on both Qt 6.8.3 and
  Qt 6.11.1; the final Qt 6.8 regression suite passed **68/68**.
