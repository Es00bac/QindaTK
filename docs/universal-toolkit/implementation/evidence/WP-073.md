## Finish lane (`work/wp073-finish`)

The finish lane closes the open numbered requirements.

- **Layer timing (requirements 1, 2 and 5).** Layer records gain
  `timeOffsetTicks` and `timeRemap` (1–1024 exact `{compTicks, layerTicks}`
  decimal pairs). `MotionComposition.evaluate` samples each layer's curves at
  `timeRemap(t − timeOffsetTicks)`, rounded once (floor) through
  `TimelineTime::mulDiv` and held outside the pairs, so freezes, reversals and
  speed ramps stay integer-exact; every evaluated layer reports `localTicks`.
  The manifest carries the fields unchanged, and malformed timing fails
  evaluation and detached load validation.
- **One transaction per gesture (requirement 3).** `AutomationModel::applyBatch`
  plans several edits (each curve at most once) and records one history step or
  nothing. `MotionComposition.movePathKey` maps a world position through the
  inverse parent matrix at the layer time and sets or adds the x/y keys there;
  `setPathTangent` edits both curves' in/out handles with one shared time-handle
  x, so the spatial segment is the 2D Bézier through the edited controls;
  `pathHandles` reports them. `MotionPathOverlay` maps world space into the
  letterboxed frame (`frameWidth`/`frameHeight`, as `CompositionView` draws it)
  or a fitted path (now y-down), shows the selected key's tangent handles and
  commits a key or handle drag with one call at release; Escape cancels.
  `insertEffect(layerId, effect, index, expectedRevision)` is one layer-record
  transaction in the composition's bounded history (`undo`/`redo`, stale
  revisions rejected); hosts answer `EffectBrowser.effectInsertRequested` with
  it. Keyframe edits already used one `applyEdit` each; `DopeSheet` emits one
  request per gesture and refuses another while one is pending.
- **Bounded caches and stale results (requirement 4).** `MotionFrameRenderer`
  keeps a least-recently-used frame cache (default 8, at most 64 frames and
  128 MiB) keyed by canonical ticks and size, for the current content revision
  only. Layer, curve (including gesture previews), source, effect-processor and
  roto changes clear it and emit `contentInvalidated`; `frameRevision` trails
  `contentRevision` while the displayed frame is stale, for example after a
  failed re-render. `CompositionView` with `timeTicks` re-requests its frame
  after each invalidation and exposes `frameStale`. `OnionSkinView` marks its
  snapshots `stale` on edits or retiming and queues one refresh that replaces
  all three frames only when every render succeeds.

Defects fixed on the way: `MotionPathOverlay` used the nonexistent theme roles
`size.controlHeight` and `size.iconSmall`, so its hit threshold never applied
and key dots had a NaN radius; it now uses `size.control` and `size.iconSm`.
`MotionComposition.animationModel` now names its namespace in `Q_PROPERTY`, so
qmllint resolves it.

### Scope notes

- Media decoding beyond still local/qrc images, external asset resolution and
  relink remain [WP-070](../phase-06-video.md#wp-070) (decode/frame/cache
  backend, proxies, relink). Compositions keep stable `sourceId` references and
  now report each layer's `localTicks`, the time a host decodes for.
- Encoded movie or image-sequence output, render jobs and resume remain
  [WP-078](../phase-06-video.md#wp-078) render queues; output-fidelity
  comparison remains [WP-089](../phase-07-integrations.md#wp-089). This
  package's export claim is deterministic per-tick PNG frames.
- Asynchronous or GPU frame rendering and decoder cancellation remain WP-070
  (GPU/software frame transfer, decoder cancellation). This renderer is
  synchronous on the caller's thread, so stale results are handled with content
  revisions instead of job cancellation.
- Dope-sheet exposure storage stays in the host animation/sequence model (the
  VID-11 dependency boundary); the toolkit view emits one request per gesture.
- The order of undo between the composition's layer-record history and the
  AutomationModel key history is owned by the host document session; each
  gesture lands in exactly one of them.
- Roto masks still sample the composition frame index (the WP-075 contract),
  not layer-local time.

records and layer timing, each an undoable transaction) and produces
deterministic sampled and exported frames that survive save/reopen byte for
