# WP-073 — Motion composition and keyframe editing

**State: active; package not accepted.**

The isolated Luna lane `work/wp073-motion` (`f68ba86`) supplied
`MotionComposition`, `KeyframeTimeline`, `DopeSheet` and `EffectBrowser`.

parent IDs and cycles, and returns deterministic affine transforms, inherited
opacity/visibility and layer order. The timeline edits the underlying
`AutomationModel` through transactions. Dope-sheet exposure requests and
effect insertion still depend on host acknowledgments.

test passed 3/3, and the motion and gallery fixtures instantiated. The
[motion authoring screenshot](WP-073-motion-authoring.png)
was opened and inspected: it shows evaluated layer transforms, key rows,
exposure cells and effect compatibility states.
