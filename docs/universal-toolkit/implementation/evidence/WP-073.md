# WP-073 — Motion composition and keyframe editing

**State: active; package not accepted.**

The isolated Luna lane `work/wp073-motion` (`f68ba86`) supplied
`MotionComposition`, `KeyframeTimeline`, `DopeSheet` and `EffectBrowser`.
The evaluator samples typed automation curves at exact ticks, validates
parent IDs and cycles, and returns deterministic affine transforms, inherited
opacity/visibility and layer order. The timeline edits the underlying
`AutomationModel` through transactions. Dope-sheet exposure requests and
effect insertion still depend on host acknowledgments.

The isolated build used the configured `-j24 -l24` limits. Its focused QML
test passed 3/3, and the motion and gallery fixtures instantiated. The
[motion authoring screenshot](WP-073-motion-authoring.png)
was opened and inspected: it shows evaluated layer transforms, key rows,
exposure cells and effect compatibility states.
After integration, the merged focused QML test passed 3/3 and the
1480×1060 fixture screenshot was regenerated and inspected.

`MotionFrameRenderer` now draws host-supplied images using the evaluator's
exact-tick affine matrices, visibility, opacity and z order. `CompositionView`
shows the latest CPU frame; the fixture loads two local SVG sources and
composites them instead of drawing stand-in rectangles. The focused C++
pixel test passed for overlapping source-over layers and PNG export/reopen.
The [composited-frame screenshot](WP-073-composited-frame.png) was opened and
inspected. Its dump places `CompositionView#compositionView` at
`0,0 795x383` and `MotionFrameItem#compositionFrame` at `4,4 787x375`.

`MotionPathOverlay` now samples composition transform origins at host-supplied
exact ticks and requests stable-ID key selection. `OnionSkinView` renders
actual neighboring composites with tinted silhouettes and restores the
current frame. The isolated configured-limit build, focused 3/3 C++ pixel
test, focused 3/3 QML interaction test, fixture check and inspected compact
screenshot passed.
The merged focused C++ and QML tests passed. The
