# WP-031 — Analytical charts and scheduling

**State:** active. Heatmap DAT-14 and DistributionPlot DAT-16 source, examples,
tests and documentation are merged into the integration worktree. Their isolated
lane results are recorded in [Heatmap evidence](WP-031-heatmap.md) and
[DistributionPlot evidence](WP-031-DAT-16.md); shared integration verification
is pending. GanttView, part-to-whole, OHLC and target displays are in separate
active lanes. Polar/radar and typed error bars/bands remain to implement before
package acceptance.

## Shared integration checkpoint

At the Heatmap and DistributionPlot merge, `cmake -S . -B
build/integration -G Ninja -DCMAKE_BUILD_TYPE=Debug` and plain `cmake --build
build/integration` passed under Qt 6.11.1. The configured system `MAKEOPTS`
remained `-j24 -l24`. Focused `tst_heatmap_model`,
`tst_distribution_model`, `example_heatmap`, `example_distribution-plot` and
`example_gallery` passed (5/5). Both new focused QML files passed (3/3 each).
The integration preview reported `Heatmap#heatmap 12,12 876x556` and
`HeatmapRenderer#heatmapPlot 0,0 876x556` at 900×580; the DistributionPlot
preview reported `DistributionPlot#distributionPlot 8,32 1164x264` at
1180×840. The isolated captures were opened and visually inspected after
copying them into this tree. Qt 6.8, the combined full suite, and installed
consumer gates will run with the completed WP-031 batch.
