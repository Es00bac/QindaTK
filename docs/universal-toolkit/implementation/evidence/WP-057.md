# WP-057 — Notebooks and structured blocks

**State: active; package not accepted.**

Luna's `work/wp057-notebook` implementation was integrated from `20d369c`.
`NotebookView` presents host-owned notebook sections, pages, search results,
history and page metadata. `BlockEditor` presents text, code, table, media,
ink, embed and unsupported block records. Both issue identified mutation
requests; the host supplies authoritative snapshots and acknowledges edits.

The isolated build used configured `-j24 -l24`; its focused QML checks passed
3/3 and the fixture passed `qtk-preview --check`. The integrated
[notebook screenshot](WP-057-notebook-merged.png) was opened and inspected.
The merged focused QML run passed 4/4, including a corrected host-search
case: indexed body hits show even without a metadata match, zero host results
stay empty, and clearing the query restores the page list. The merged
fixture passed `example_notebook-authoring`; its dump places
`NotebookView#fieldNotebook` at `0,24 1504x920` and
`BlockEditor#notebookBlockEditor` at `0,0 1144x788`.

Persistent notebook mutations, cross-block cursor semantics and
real table/media/embed providers remain required before acceptance.
