# WP-053 — Printing and publishing preflight

**State: active; package not accepted.** WP-051 remains active.

`RichTextDocument.exportPdf(path)` now paginates the live document, paints
each page through `RichTextLayout::paintPage`, and atomically commits a local
PDF. It uses the document page dimensions at 96-dpi layout coordinates.
Luna's `work/wp053-panels` lane was integrated as `839397a`. It adds
`PrintPreview` with a host-supplied page renderer and print/cancel request
state, and `PreflightPanel` with stable issue IDs, severity filters and
navigation/repair requests. The fixture displays a real `RichDocumentView`
beside sample preflight results.

The merged `build/integration` targeted build used `-j24 -l24`. Focused
`tst_rich_text_layout` and `example_document-review` passed 2/2. The rich
document showcase exported as a three-page A4 PDF (`pdfinfo`: 595 × 842 pt),
and `pdftotext` recovered its text. Sol inspected the [rendered first page](WP-053-pdf-page1.png): styles, mixed scripts, inline image, lists and the table are present.
The isolated panel build also used `-j24 -l24`; its focused cancellation test
passed 3/3, and the fixture preview check passed. Sol inspected the
[print and preflight screenshot](../../../screenshots/wp053-print-preflight.png):
page preview, output settings and issue details are visible.
The merged `example_print-preflight` CTest smoke also passed.

Printer enumeration/jobs, actual cancellation/recovery, definitive output
capability negotiation, backend preflight checks and bounded preview caches
remain open. The controls and PDF file path do not satisfy WP-053 acceptance.

**Accept when.** Print preview, PDF files and printer jobs share one sheet
geometry and one painter, and tests compare their pixels and page boxes.
Cancelled and failed jobs leave no output, keep the ticket, name the affected
pages, and a retry succeeds. The
[print and preflight example](../../../../examples/print-preflight/Main.qml)
now drives `PrintPreview`, `PrintSheetView` and `PreflightPanel` from one
`PrintAdapter` over the showcase document.

Scope notes: section and page-scoped page geometry (left refused by WP-051)
stays refused. `RichTextLayout` and the views assume one page size, and no
package owns that change yet (D-133). CUPS job tracking after hand-off is not
included; "completed" means the spooler accepted the job. Performance
measurement, other platforms and output-fidelity comparison are WP-088 to
WP-094.
