# WP-072 — Captions, scopes and grading controls

**State: active; package not accepted.**

Luna's `work/wp072-caption-color-wheels` commit `ccadfd4` supplied
`CaptionEditor` and `ColorWheels` with a combined preview fixture. Caption
gestures pass host-owned exact time strings, and editing issues text, style,
timing and export requests. Wheels accept host-defined numeric ranges and
send preview, finish, cancel and reset requests. The controls display host
acknowledgments but do not mutate media themselves.

The isolated build inherited configured `MAKEOPTS=-j24 -l24`; focused QML
checks passed 2/2 and the preview instantiated. The merged Qt 6.11 build,
focused QML test (4/4 including init/cleanup), example smoke and catalog
check passed. The merged dump places `CaptionEditor#captionEditor` at
`0,0 1256x252` and `ColorWheels#colorWheels` at `0,0 1256x344`.
The [1280×760 screenshot](WP-072-caption-color.png) was opened and inspected.

Luna's `work/wp072-video-scopes` commit `87a5fc0` added
`VideoScopesModel::analyzeFrame(QImage, frameId)` and `VideoScopes`.
The bounded CPU path produces waveform, luma histogram and Rec.709
Cb/Cr vectorscope bins from host-decoded images. It states its encoded-sRGB
and full-range assumptions, and does not claim broadcast decoding. The
isolated focused test passed; after integration, the focused C++ test passed.
The [900×650 scopes screenshot](WP-072-video-scopes.png) was opened and
inspected. Its dump places both `VideoScopes#videoScopes` controls at
`0,0 430x224` and `438,0 430x224` within the fixture Flex.

Luna's `work/wp072-grade-processor` commit `5cb3889` added
`ColorGradeProcessor` and `ColorGradePreviewModel`. The processor accepts
ICC-tagged decoded images, converts into linear sRGB, applies exposure and
lift/gamma/gain wheel coordinates, and emits tagged output with preserved
alpha. Its focused numerical test passed in the isolated worktree. The
fixture displays before/after pixels and scopes using the same analyzer.

Remaining: caption serialization and render/export, video decode/playback,
grade undo/session integration, broadcast/codec fidelity, calibrated display
output and the WP-072 completion checks. The host supplies decoded frames
and owns grade transactions.
