# WP-072 — Captions, scopes and grading controls

**State: active; package not accepted.**

Luna's `work/wp072-caption-color-wheels` commit `ccadfd4` supplied
`CaptionEditor` and `ColorWheels` with a combined preview fixture. Caption
gestures pass host-owned exact time strings, and editing issues text, style,
timing and export requests. Wheels accept host-defined numeric ranges and
send preview, finish, cancel and reset requests. The controls display host
acknowledgments but do not mutate media themselves.

The isolated build inherited configured `MAKEOPTS=-j24 -l24`; focused QML
checks passed 2/2 and the preview instantiated. The merged Qt 6.11 build,
focused QML test (4/4 including init/cleanup), example smoke and catalog
check passed. The merged dump places `CaptionEditor#captionEditor` at
`0,0 1256x252` and `ColorWheels#colorWheels` at `0,0 1256x344`.
The [1280×760 screenshot](WP-072-caption-color.png) was opened and inspected.

Luna's `work/wp072-video-scopes` commit `87a5fc0` added
`VideoScopesModel::analyzeFrame(QImage, frameId)` and `VideoScopes`.
The bounded CPU path produces waveform, luma histogram and Rec.709
Cb/Cr vectorscope bins from host-decoded images. It states its encoded-sRGB
and full-range assumptions, and does not claim broadcast decoding. The
isolated focused test passed; after integration, the focused C++ test passed.
The [900×650 scopes screenshot](WP-072-video-scopes.png) was opened and
inspected. Its dump places both `VideoScopes#videoScopes` controls at
`0,0 430x224` and `438,0 430x224` within the fixture Flex.

Luna's `work/wp072-grade-processor` commit `5cb3889` added
`ColorGradeProcessor` and `ColorGradePreviewModel`. The processor accepts
ICC-tagged decoded images, converts into linear sRGB, applies exposure and
lift/gamma/gain wheel coordinates, and emits tagged output with preserved
alpha. Its focused numerical test passed in the isolated worktree. The
fixture displays before/after pixels and scopes using the same analyzer.
The merged build and focused processor test passed. The
[1280×800 grade screenshot](WP-072-color-grade.png) was opened and inspected:
it shows changed output pixels and different before/after histograms.
The dump places the two `VideoScopes` at `0,0 624x224` and
`632,0 624x224` in the bottom fixture row.

`CaptionTrackModel` now supplies stable cue IDs, exact decimal-millisecond
timing, same-lane overlap checks, preview/commit/cancel, local undo, atomic
JSON persistence and WebVTT/SRT sidecar import/export. The isolated focused
model test and fixture check passed. Its `examples/caption-model` fixture
shows the model connected to `CaptionEditor`.
The merged caption-model test passed. The
[1100×750 caption screenshot](WP-072-caption-model.png) was opened and
inspected; the dump places its editor at `0,0 1076x540` and shows selected
exact timing `1200–4300` milliseconds.

`CaptionFrameRenderer` now burns active cues into a host-supplied `QImage` at
an exact decimal-millisecond time. It honors `[in,out)` cue intervals, stable
lane/start/ID order, the existing default/emphasis styles and saves PNG
atomically. The isolated configured-limit build, focused 3/3 renderer tests,
fixture check and inspected screenshot passed.
The merged focused renderer test passed. The
[1440×900 caption screenshot](WP-072-caption-render.png) was opened and
inspected: two overlapping cue lanes appear as pixels in the output image.
The dump places `Image#burnedCaptionPixels` at `0,0 795x779`.

`CaptionSequenceExporter` now writes ordered, burned-in PNG frames and a
`timing.json` manifest with exact decimal-millisecond timestamps and active
cue IDs. A host supplies frame pixels; a sibling staging directory is renamed
only after every frame and the manifest are written. The merged
configured-limit build and focused sequence test passed. The
[1120×700 sequence screenshot](WP-072-caption-sequence.png) was opened and
inspected: both overlapping captions are visible as rendered pixels, and
the fixture reports five exported frames.

`ColorGradeEditSession` now owns a tagged host frame, a preview/cancel edit
gesture, one shared `EditTransaction`/`UndoService` undo step per committed
gesture, redo, and rendering through `ColorGradeProcessor`. Switching the
host frame invalidates that frame's edit history. The configured-limit merged
build and focused session test passed. The
[1280×900 session screenshot](WP-072-grade-session.png) was opened and
inspected; the before/after images and histogram scopes show different actual
pixels, and the dump places `VideoScopes#gradeBeforeScopes` and
`VideoScopes#gradeAfterScopes` at `0,0 624x224` and `632,0 624x224`.

Remaining: embedded caption output, video
decode/playback, broadcast/codec fidelity, calibrated display output and the
WP-072 completion checks. The host supplies decoded frames.
