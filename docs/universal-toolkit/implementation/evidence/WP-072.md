### Requirements

1. **Caption intervals/styles, sidecar/embedded capabilities, scope signal
   conventions, grading parameter spaces: built.** `CaptionTrackModel.formats`
   states what JSON, WebVTT, SRT, embedded Matroska SubRip and burn-in carry
   (D-128). `VideoScopeConvention` states matrix, 8-bit code range and
   analysis space, echoed in every snapshot (D-127).
   `ColorGradeEditSession.wheels`/`gradeSpace` declare the wheel ranges and the
   zero-sum opponent space (wheels change chroma, never luma). Tests:
   `tst_caption_track_model` `webVttKeepsEveryLanguage` (formats),
   `tst_video_scopes` `conventionsTargetsAndSignalSpace`,
   `tst_color_grade_edit_session` `wheelAndNumericEntryBuildTheSameGrade`.
2. **Real caption timing/edit/serialization and render/export paths: built.**
   Split, merge and shift, each one undo step; reading warnings (overlap,
   short, reading rate, line length); WebVTT language header and `<lang>`
   spans with entity escaping. Output: burned-in captions through
   `CaptionBurnIn` in program playback and export (`VideoFinishing`,
   `MediaFinishing`), and an embedded SubRip stream written by `MediaEncoder`
   and read back by `MediaCaptions::readEmbedded` /
   `CaptionTrackModel.importEmbedded`. Tests: `tst_caption_track_model`
   `splitMergeShiftAndUndo`, `webVttKeepsEveryLanguage`;
   `tst_video_finishing` `burnedAndEmbeddedCaptionsReachTheExport`,
   `encoderDropsSubtitlesAfterTheLastFrame`.
3. **Waveform/vectorscope/histogram from decoded frames with explicit range,
   transfer and channel conventions: built.** Waveform, RGB parade, Y′ and
   RGB histograms, vectorscope with 75%/100% targets, exact code extents;
   `VideoScopes` gains `parade`, targets and level lines. `VideoScopesModel`
   binds to a `MediaPlayer`, analyzes once per presented frame while active
   and names each snapshot with the frame's `presentedFrameKey`. Tests:
   `tst_video_finishing` `scopesMeasureDecodedBarsUnderStatedConventions`
   (FFV1-decoded 75% bars: Rec.709 and Rec.601, limited and full),
   `playerScopesFollowFramesAndShowTheFinishing`; `tst_video_scopes`.
4. **Wheel gestures and an actual grade transform in the output pipeline
   using ColorContext: built.** The session's `previewWheel`/`finishWheel`
   (drag) and `setWheelValue`/`setExposure`/`resetWheel` (numeric) build the
   same parameters; `ColorWheels.requestWheelValue` emits the drag's signals.
   `MediaFinishing` grades every program frame through `ColorGradeProcessor`
   in a fixed `ColorContextSnapshot` (D-126); the processor now works on
   float linear pixels, so a neutral grade no longer bands shadows.
   Tests: `tst_video_finishing` `gradeMatchesTheSessionPreviewAndTheExport`;
   QML `tst_color_grade_wheels.qml` (a pointer drag and numeric entry on
   ColorWheels bound to a real session, one undo step each) and
   `tst_caption_color_wheels.qml` `test_numeric_value_emits_the_drag_signals`.
5. **Verify caption overlaps/boundaries, multilingual output, known bars and
   scopes, grade undo and exported colour: tests written.** `[in, out)`

   overlapping cues in two lanes burned and embedded; Japanese, Arabic and
   Greek text through WebVTT, burn-in and the embedded stream; Rec.709/601 bar
   codes; grade undo back to an identity export; graded export frames decode

Toolkit defects the example exposed, each with a test:
- A `ProgramGrade` session rejected every gesture and disabled its wheels
  without a host frame, which a QML host cannot supply
  (`tst_media_finishing_live`).
- `VideoScopes` painted a long frame ID (a `presentedFrameKey`) over the
  mode title, and clipped the yellow 100% label in a near-square
  vectorscope (`tst_video_scopes_header`).
- `qtk-preview --check` leaked its root, so a running `MediaCatalog`
  test-signal job painted during static teardown and crashed (SIGSEGV
  in 5 of 6 runs). The root is now destroyed while the engine and the
  application still exist; `example_grading-scopes-live` is the regression.
