Restoring other content moves the reset generation and drops the history. A fill drag cut short fills nothing, and a damaged clipboard payload changes nothing. |

IME: the editor is a text input and accepts composition, but type-to-edit reacts to key events only, so composed text starts from Enter or F2. |

## Proposed boundaries

These need Sol's approval. Each names why it is outside this lane and where
it belongs.

- **B-1 XLSX/ODS interchange.** Both formats are ZIP packages of XML parts,
  and the toolkit has no package reader or writer. WP-055 requires declared
  interchange operations with tests, which CSV/TSV (import and export, with
  declared losses) provide. Office-format fidelity belongs to WP-089 or a
  package backend.
- **B-3 Function families** beyond the documented 13 (lookup, date, text,
  statistical, volatile), 3-D references and array formulas. The package
  requires a declared function capability list, which is documented and
  tested.
- **B-4 Assistive technology runs.** Roles, names and actions are set and
  checked at the QML level. AT-SPI or screen-reader sessions and GPU-backend
  captures were not run in this environment.

B-2 (DocumentManager membership) is resolved: with D-053 the workbook is a
domain document, so `DocumentManager` creates, opens, saves, recovers and
closes it through the workbook codec (`tst_workbook_session`, the example
and the installed consumer).
