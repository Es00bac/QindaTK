## Delivered

- **Engine** (`workbook_value`, `workbook_formula.h`, `workbook_parser`,
  `workbook_refs`, `workbook_eval`, `workbook*.cpp`): stable `sheet-N` IDs
  that are never reused, ordered and renameable sheets, sparse typed cells
  (blank/number/text/boolean/error), formulas with cached values and explicit
  error values including `#CYCLE!`. The documented grammar has 13 functions
  (SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF, IFERROR, AND, OR, NOT, ABS,
  ROUND). Relative/absolute anchors, cross-sheet references by ID, parse
  errors with UTF-16 spans and canonical rendering are included.
- **Recalculation:** a cell/range dependency index; the dirty closure is
  ordered with Kahn's algorithm, iterative Tarjan SCCs give cycles, and every
  formula is evaluated once per commit. Instrumentation reports dirty,
  evaluated and cycle counts and time.
- **Operations:** edit, paste, formula-aware copy, fill, clear, row/column
  insert/remove, sheet add/remove/rename/move. Each validates first and is
  one atomic, reversible step. Explicit transactions group operations and
  can be cancelled exactly. Exact inverse mutations are recomputed on every
  undo/redo; the Workbook is the only revision/history owner.
- **Persistence:** `qindatk.workbook` version 1 (canonical compact JSON,
  `.qtkwb`). `serialize`/`restore`, atomic `save`/`open` through the
  existing `FormatIO` helpers with a SHA-256 conflict check, and a
  `WorkbookFormat` FormatProvider registered with `Workbook.registerFormat`.
- **Views:** `WorkbookSheetAdapter` (C++) presents a sheet through the
  unchanged `EditableGridModel` contract. `SheetView`, `FormulaBar` and
  `WorkbookTabs` (QML) build on `Tk.EditableGrid`; `examples/workbook/Main.qml`
  exercises them.
- **Documentation:** [workbook.md](../../../workbook.md) (contract, grammar,
  functions, rules, format, gaps), the controls.md section, a docs index
  row, the examples README section, decision D-055 (provisional number) and
  the regenerated catalog (5 new types, no existing entry changed).

## Dependencies, gaps and observations

- WP-028 EditableGrid and WP-019 FormatRegistry are consumed unchanged.
  Gaps G-1 to G-8 in [workbook.md](../../../workbook.md#gaps-in-consumed-contracts)
  cover: display-equal commits dropped by the grid, no source-change
  notification, stale `activeRow`/`activeColumn` after moves, no per-cell
  presentation or fill-handle hook, and display-value fill. They also cover
  registry export accepting only `PropertyDocument`/`DocumentSession`,
  `UndoService`/`DocumentSession` being `PropertyDocument`-only, and
  O(rows) grid identity. Each is worked around in the adapter/SheetView with
  a marker comment, and each has a proposed change for its owner.
- The QML ahead-of-time compiler drops a dependency that is read into an
  unused local in a binding block (`{ const e = epoch; return … }`); the
  SheetView bindings therefore use `epoch` in the value (AGENT-GUARD in
  `SheetView.qml`). EditableGrid uses the same pattern inside a function, where it
  still works; it is noted here in case that function is ever compiled.
- `StandardKey.Redo` already contains Ctrl+Y on this platform; listing both
  made the shortcut ambiguous, so SheetView lists explicit sequences.
- `tools/scripts/gen_catalog.py` records no signals for any C++ type (0 of
  86 before this change): signal lines never reach its statement filter.
  Not changed here (shared tool).
