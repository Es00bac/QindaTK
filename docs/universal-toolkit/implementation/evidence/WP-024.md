# WP-024 — Typography and calendar value pickers

**State: review.** Proposal scope: CTL-18 FontPicker, CTL-19
FontFeaturesEditor, CTL-22 DateTimeField and CTL-23 CalendarPicker. APIs,
objectNames and provider limits are in [controls](../../../controls.md#typography-calendar-and-format-dialogs)
and [locale behavior](../../../accessibility-locale-input.md).

## Behavior delivered

- `FontCatalog` lists installed families and styles, resolves an unavailable
  family without discarding its name, and reports fallback. The font metadata
  follow-up reads `fvar`, `GSUB` and `GPOS` from the selected installed face
  to expose actual axis bounds and feature tags. A host sample can now check
  face-level Unicode coverage through `QRawFont` and display missing code
  points in `FontFeaturesEditor`; shaping and fallback remain unverified.
  Picker edits go through `PropertyBinding`;
  a family/style pair uses one undo macro, while a specimen renders the
  selected face or explicit fallback.
- `LocaleService` supplies date-only parse/format, calendar-native month
  fields and a 42-cell grid with stable Gregorian ISO date IDs. It classifies
  local wall times as valid, ambiguous or nonexistent in the selected zone.
  `DateTimeField` requires explicit choice between repeated UTC instants and
  rejects a daylight-saving gap. Inclusive canonical bounds reject out-of-range
  dates or selected UTC instants, and clearing is a binding transaction.
  `CalendarPicker` offers bounded single-date
  and range selection with keyboard navigation.

## Boundaries

The font service checks code point coverage in one selected face's cmap; it
does not expose a shaping engine, fallback resolution or per-script feature
eligibility. A result that says every code point is present cannot guarantee
the final shaped text. The calendar emits date identities;
recurrence, scheduling and cross-zone event semantics belong to an
application/provider. Date-time fields store selected UTC instants rather
than ambiguous local text.

WP-024 remains in review for fresh integrated dual-Qt and installed-consumer
checks after this change.
