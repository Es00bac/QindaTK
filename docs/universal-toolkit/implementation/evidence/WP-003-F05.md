# WP-003 / FIX-F05 — KeyCap and Filmstrip layout conversion

Status: **F05 integrated and verified; WP-003 remains open** for F06 and DOC-01.

The pre-existing audit-fix commit `09bcda4` was reviewed and only its
`KeyCap.qml`, `Filmstrip.qml` and matching media documentation were reused.
Both QtQuick `Row` positioners became `Tk.Flex` rows. KeyCap wraps its Flex in
an `Item` to retain the implicit-size contract. Filmstrip keeps its explicit
frame-count and tail-frame mapping. New stable objectNames are `keyCapRow`
and `filmstripRow`; the existing child names remain.

## Verification on the integration worktree

- Baseline captured in [WP-001](WP-001.md) at compact and comfortable density.
- Reconfigured with `cmake -S . -B build/integration -G Ninja
  -DCMAKE_BUILD_TYPE=Debug` after adding the QML test file (exit 0).
- Read `portageq envvar MAKEOPTS` immediately before the direct build:
  `-j24 -l24`. Ran `ninja -C build/integration -j24 -l24` (exit 0).
- `ctest --test-dir build/integration -R '^tst_qml$'
  --output-on-failure`: 1/1 passed. The focused tests check Flex child
  structure, implicit sizing, gap, equal frame widths, height and the tail.
- `qtk-preview` dumped and grabbed the same 640×360 fixture in compact and
  comfortable density. Both PNGs were opened and inspected. A corrected RGB
  comparison (the initial RGBA difference check was invalid because the alpha
  difference was zero) found 17 changed pixels at the last frame's rightmost
  border in each density, with no other changed region.

Compact geometry after conversion:

```text
KeyCap#probeKeyCap       0,109 640x18
  Flex#keyCapRow          0,0    77x18
  Rectangle#keyCapKey     0,0    25x18
  Rectangle#keyCapKey     27,0   30x18
  Rectangle#keyCapKey     59,0   18x18
Filmstrip#probeFilmstrip 0,131 640x40
  Flex#filmstripRow       0,0   640x40
  Thumbnail#filmstripFrame0 0,0   212x40
  Thumbnail#filmstripFrame1 214,0 212x40
  Thumbnail#filmstripFrame2 428,0 212x40
```

At comfortable density, KeyCap is 85×22 within its stretched parent and
Filmstrip is 640×48; frame widths/positions remain 212 at 0, 214 and 428.
The one-pixel border edge differs from the prior Row rendering; the shown
frame content, dimensions and positions match. This fixture does not prove
every possible consumer sizing. F06 and DOC-01 are still pending; WP-003
cannot be accepted.
