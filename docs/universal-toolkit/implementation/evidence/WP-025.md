# WP-025 — Preferences, shortcuts and find/replace

**State: review.** Proposal scope: CTL-10 ShortcutEditor, CTL-11
PreferencesDialog and CTL-25 FindReplaceBar. Contracts are in
[settings/workspace](../../../settings-workspace.md),
[commands](../../../commands.md), [find/replace](../../../find-replace.md)
and the [control catalog](../../../controls.md).

## Behavior delivered

- PreferencesDialog stages registered SettingsModel descriptors, validates
  values, separates Apply from Cancel, exposes reset and restart indication,
  and keeps schema authority in C++.
- ShortcutEditor captures portable sequences, validates active-scope
  conflicts through ShortcutMap, persists JSON text in the registered
  `app:shortcuts.overrides` setting, and reloads it into a fresh map.
  Capture completion, Escape and Tab restore focus to the stable row or
  search-field fallback; the host also receives `focusReturnRequested`.
- FindReplaceBar uses FindReplaceService against a real QQuickTextDocument.
  Search snapshots run off the GUI thread, reject stale revisions, support
  scope/cancellation, and block replacement in read-only or composition state.
  Replace All uses one QTextCursor edit block so one undo reverts the group.
