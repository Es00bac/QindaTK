**Accept when.** CLAP is the one declared format and has the lifecycle,
audio and state fixtures above. LV2 and VST3 are declared unavailable, not
advertised, so they owe no evidence; a later adapter brings its own.

**Scope notes.** LV2 (lilv is not installed and is not a dependency) and
VST3 (SDK absent) adapters are not built. Not supported by the CLAP host:
side-chains, surround and 64-bit ports, transport information for plugins,
sample-accurate automation inside a block (values change at block starts,
at most 256 frames apart), presets (`PluginBrowser` preset preview stays a
host request), a shared host process for several instances, and Wayland
editor embedding. Editor embedding on a real X server and window-manager
focus behaviour, performance measurement (per-instance process and context
switch cost), other platforms, screen-reader runs and translation belong to
WP-088 to WP-094.
