# WP-082 — Collaboration, presence and version history

**State: active; package not accepted.** A Sol implementation lane is building
a bounded local two-client synchronization core for typed property edits,
deterministic conflict handling, offline reconnect and separate ephemeral
presence. Its focused build and convergence checks are pending. Generic domain
operations, permissions and version browse/restore remain part of the full
WP-082 acceptance scope.

**Accept when** (two real local clients converge under documented rules and
recover from offline edits; presence and history correctly scoped): covered by
the child-process TCP and local-socket cases plus the in-process network

`docs/collaboration.md`.
