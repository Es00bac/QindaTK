# WP-051 — Publishing structure, styles and tables

**State: active; package not accepted.** WP-042 is still active and WP-050
remains in review.

Luna's isolated `work/wp051-panels` lane was integrated as `c979c6d`.
It adds `StyleManager`, `PageSetupDialog`, `TextFrameEditor`, and `TableEditor`.
The QML fixture owns the sample style, page, frame and table records and
applies the controls' requests. The production rich-text/page backend has
yet to implement canonical style inheritance, linked frame flow, structured
table edits and page geometry transactions.

The isolated Qt 6.11 targeted `qtk-preview` and `tst_qml` build used
`-j24 -l24`. The focused table insertion test passed 3/3, and the fixture
passed `qtk-preview --check`. Sol inspected the [publishing workbench](WP-051-publishing.png)
and [open page setup dialog](WP-051-page-setup.png): populated values, orientation
and controls are legible. A merged-tree build is queued with the other
concurrent QML control lanes to avoid repeating full QML cache compilation.
