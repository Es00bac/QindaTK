# WP-029 — Filters, query building and pivots

**State: review.** Proposal scope: DAT-07 FilterBar, DAT-08 QueryBuilder and
DAT-09 PivotView. The typed core, asynchronous QML controller and visual
controls are integrated. The [visual evidence](WP-029-visual.md) records the
isolated lane's focused tests and inspected captures. Shared and installed
package qualification remains open.

## Foundation delivered and checked

- `QuerySpec` supplies typed schema metadata, parameter values, a typed
  predicate tree, grouping axes and aggregation descriptors. Versioned JSON
  preserves signed 64-bit values. Three-valued filters distinguish null,
  false and error. Capability negotiation rejects unsupported requests.
- `QueryEngine` scans projected source fields with row/group/cell/provenance
  bounds, atomic cancellation and schema/source revision guards. It computes
  count rows, count values, sum, average, minimum and maximum. Typed dimension
  hashes make row/column IDs stable; source row IDs retain drill-through
  provenance. Remote providers have an explicit execution seam.
- `GridQuerySource` reads an `EditableGridModel` lazily by stable IDs.
  `queryResultAsGrid` produces a presentation snapshot with model-enforced
  read-only flags and mutation guards.
- `QueryController` exposes versioned query/schema maps to QML, bounded
  GUI-thread snapshot collection, worker evaluation, cancellation, atomic
  publication, read-only result model, labels and drill-through source IDs.
- Isolated full build completed at configured parallelism. Focused CTest
  `tst_query_core` and `tst_editable_grid_model` passed **2/2**. The five-row
  known-answer fixture yields East/A sum **30**, average **15**, East/B
  count-rows **1** and count-values **0**, grand sum **50**, grand average
  **12.5**, and East/A provenance `[r1, r2]`. Filtering `amount >= 10`
  yields three rows and sum **45**. Tests also cover null unknown/is-null,
  JSON roundtrip past 2^53, stale source/schema, schema change during scan,
  cancellation, output limits, stable IDs after reorder, grid source and
  read-only snapshot rejection.
- The same two focused CTest targets passed **2/2** after the core was copied
  into the shared Qt 6.11 integration build. `git diff --check` passed.
- The QML-facing controller focused test passed **5/5** on Qt 6.11.1 in the
  isolated lane, including asynchronous publication, labels and provenance,
  enforced read-only result, immediate cancellation, source-edit rejection
  and deterministic request ID on malformed input. The incremental module
  build passed at configured parallelism. The same focused QML test passed
  **5/5** after integration. This is not yet the supported-Qt or
  installed-consumer gate.
