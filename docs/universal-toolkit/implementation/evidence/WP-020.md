# WP-020 — Command controls and adaptive toolbars

**State: review.** Proposal scope: CTL-01 SplitButton, CTL-02 MenuButton,
CTL-03 ToolShelf, CTL-05 CommandBar and CTL-06 OverflowToolBar. Public
properties and stable objectNames are in [controls](../../../controls.md#command-composition-and-typed-inspectors).

## Behavior delivered

- SplitButton keeps a primary command invocation separate from its menu
  segment. MenuButton opens choices and retains the selected command identity.
  Both use the existing registry/menu command path and restore focus when the
  popup closes.
- ToolShelf emits explicit persistent and temporary tool requests; the host
  owns tool state. CommandBar keeps user order by stable command ID and lets a
  bound property slider edit through one `PropertyBinding` transaction.
- OverflowToolBar measures visible text, keeps grouped commands together,
  spills by priority, and transfers keyboard focus to the overflow menu if
  the focused command moves there on resize.

## Verification

- The Luna implementation's focused Qt 6.11 QML fixture passed 8/8 cases;
  the full `tst_qml` target and `all_qmllint` exited 0 in its isolated build
  under the configured `-j24 -l24` equivalent. The root reviewed compact
  880×440 and comfortable 1040×520 preview grabs. In the compact fixture,
  `OverflowToolBar` occupies a 257px content width in a 320px host and keeps
  two actions visible with an overflow affordance.
- The integrated Qt 6.11 full suite passed 57/57. A fresh Qt 6.8 run passed
  all WP-020 QML cases; three unrelated active WP-021/WP-026 QML cases kept
  the global QML target open. Installed Qt 6.11 and Qt 6.8 consumers imported
  `CommandBar` and `OverflowToolBar`. The preview's command buttons have no registered
  action handlers; behavior is tested with the QML fixture and WP-011 command
  service tests, not inferred from the static image.

## Boundaries

Applications supply the command registry, command IDs and property bindings.
The toolkit reports invocations and ordering; it does not persist a user's
custom toolbar order unless the host stores it in settings/workspace state.
