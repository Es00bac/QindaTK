# WP-081 — Extensions and developer surfaces

**State: active; package not accepted.**

`Tk.TerminalSession` is merged on the integration branch. It owns a real
user-initiated Unix PTY process, libvterm-parsed styled rows and cursor,
bounded scrollback, UTF-8 input, resize, copyable text and process cleanup.
Constructing the session does not start a process. The isolated configured
build and focused `tst_terminal_session` passed. See
[terminal-session.md](../../../terminal-session.md) for the API and limits.

The merged configured build and `tst_terminal_session` passed 1/1.
`TerminalView` and its explicit-start live PTY example are merged. The Luna
lane passed its focused QML test 3/3, then captured and inspected both an idle
screen and [actual ANSI-colored process output](WP-081-terminal-live-output.png).
`CodeDocument` and `CodeEditor` are merged. They use a native Qt text document
for Unicode editing, IME, undo and UTF-8 save/reopen, with revision-tagged
syntax and diagnostics. The isolated C++ check passed 1/1, focused QML check
3/3, and the [live editor screenshot](WP-081-code-editor.png) was opened.
Folding, multi-cursor, completion and language-service integration remain open.

`ScriptRuntime` and `ScriptConsole` are merged. The runtime evaluates bounded
local JavaScript against JSON-only snapshots and an explicit command allowlist,
then replays commands on the owner thread with optional semantic undo grouping.
Its isolated focused C++, QML and example checks passed; the
[live console screenshot](WP-081-script-console.png) was opened. It is not a
process sandbox and does not expose arbitrary application objects.

The merged terminal/editor/script control checks are pending one combined QML
build. An ExtensionRegistry implementation lane is finishing its focused test.
Cross-platform terminal adapters, multi-line selection, persistent macro files
and the full WP-081 acceptance remain open.
