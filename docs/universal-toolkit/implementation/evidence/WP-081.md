# WP-081 — Extensions and developer surfaces

**State: active; package not accepted.**

`Tk.TerminalSession` is merged on the integration branch. It owns a real
user-initiated Unix PTY process, libvterm-parsed styled rows and cursor,
bounded scrollback, UTF-8 input, resize, copyable text and process cleanup.
Constructing the session does not start a process. The isolated configured
build and focused `tst_terminal_session` passed. See
[terminal-session.md](../../../terminal-session.md) for the API and limits.

The merged configured build and `tst_terminal_session` passed 1/1.
`TerminalView` and its explicit-start live PTY example are merged. The Luna
lane passed its focused QML test 3/3, then captured and inspected both an idle
screen and [actual ANSI-colored process output](WP-081-terminal-live-output.png).
The merged control check is pending the next QML build. CodeEditor, scripting
runtime and extension registry implementation lanes are active. Cross-platform
terminal adapters, multi-line selection and the full WP-081 acceptance remain
open.
