# WP-085 — Scientific plotting

**State: active; package not accepted.**

A Sol implementation lane is building a reusable scientific figure surface
against the accepted chart framework: typed numeric datasets, units,
uncertainty, calibrated axes, cursor selection, and reproducible PNG/SVG
output. Its isolated build and focused verification are pending. 3D
scatter/surface rendering and the full WP-085 acceptance scenario remain open.
