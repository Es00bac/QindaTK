# WP-085 — Scientific plotting

**State: active; package not accepted.** This record covers the first 2D
measurement slice, not the full scientific plotting package.

## Working capability

`Tk.ScientificDataset` ingests 1D ordered float64 X/Y samples with stable IDs,
declared units, optional host-supplied one-sigma Y uncertainty and explicit
missing Y. It validates a complete replacement before publishing it. The
full source remains available in a `QAbstractListModel`, CSV and deterministic
JSON figure metadata with SHA-256 of all samples and host parameters.

`Tk.ScientificPlot` uses the existing `ChartAxis` and `UncertaintyView` paths
for calibrated linear/log axes, error bars or bands, data-coordinate cursor,
stable sample selection and a full source table. The renderer paints the
figure title and preserves source and render parameters in PNG/SVG metadata.

## Focused verification

- `cmake --build build/wp085-scientific --target tst_scientific_plot qtk-preview -- -j24 -l24` (configured system `MAKEOPTS=-j24 -l24`): passed.
- `ctest --test-dir build/wp085-scientific -R '^tst_scientific_plot$' --output-on-failure`: 1/1 passed. It checks known `y=x²` sample values, missing Y, invalid replacement atomicity, log-axis cursor round trip, selected source ID, real PNG/SVG files and embedded provenance.
- `qtk-preview examples/scientific-plot/Main.qml --check`: passed.
- `qtk-preview examples/scientific-plot/Main.qml --dump --size 1080x680`: `ScientificPlot#scientificExampleFigure 8,8 1064x664`; `UncertaintyView#scientificPlotCanvas 0,0 1064x664`; `UncertaintyRenderer#uncertaintyPlot 0,0 1064x664`.
- [WP-085-scientific-plot.png](WP-085-scientific-plot.png) was captured at 1080×680 and visually opened. It shows 18 distinct exponential-decay points, readable error bars, calibrated ticks, source units and a figure title.

## Remaining WP-085 scope

This is one 2D series with symmetric Y uncertainty. Multi-series panels,
asymmetric/X error bars, sampled surfaces, 3D scatter/surface rendering,
out-of-core numeric arrays and figure layout composition are still open.
The package must remain active; this slice is not WP-085 acceptance.
