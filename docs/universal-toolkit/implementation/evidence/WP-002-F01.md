# WP-002 / FIX-F01 — selectable Label

Status: **F01 integrated and verified; WP-002 remains open** for F02/F03.
Luna implemented the selection path in worker commits `181f7e7` and
`2e22eb9`. Sol integrated, reviewed and refined it in the integration branch.

`Tk.Label` remains a `Text` type with its original default appearance and
implicit size. Setting `selectable: true` creates a read-only `TextEdit`
overlay for mouse selection, tab focus, Ctrl+A and Ctrl+C. It does not request
focus on creation. Ordinary labels do not create a hidden editor or text
metrics. For a constrained no-wrap label, the overlay selects and copies the
displayed elided string. The stable internal name is `selectableText`.
Its glyph suppression uses the theme's `opacity.hidden` role; no literal
chrome color or opacity was added to the control.
