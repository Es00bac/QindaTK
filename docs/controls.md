# Controls catalog and API contract

Every QindaTK control is a QML type in `src/qml/` with the same name as the
file. Import with `import QindaTK as Tk`. This page is the contract: names,
properties, signals, sizes. `docs/catalog.json` is the machine-readable
mirror generated by `tools/scripts/gen_catalog.py`; keep both current.

## Conventions shared by all controls

| Convention | Rule |
| --- | --- |
| Base | `QtQuick.Templates as T` types for anything interactive; `Item`/`Rectangle` for passive pieces. |
| Height | `Tk.Theme.size.control` (24). `small: true` → `controlSm` (20). `large: true` → `controlLg` (28). Chips 32 (`size.chip`), island actions 36 (`size.action`), rows 22 (`size.row`), headers 24 (`size.header`), tabs 22 (`size.tab`). |
| Text | body 12px (`font.body`); captions 10px; overlines 10px uppercase semibold tracked. |
| Radius | `radius.sm` (4) for controls, `radius.md` (6) for chips/panels/popovers, `radius.full` for islands, badges, switches. |
| Colours | Only `Tk.Theme.color.*` roles. Rest: `controlBg`/`controlBorder`; hover: `controlHoverBg`/`controlHoverBorder`; active/checked: `controlActiveBg`/`controlActiveBorder`; inputs: `inputBg`/`inputBorder`/`inputFocusBorder`; chips: `chipBg`/`chipBorder`/`chipHoverBg`/`chipHoverBorder`. |
| Focus | 2px `Tk.Theme.color.focus` ring 1px outside the background, shown on `visualFocus`. |
| Disabled | `opacity: Tk.Theme.opacity.disabled`. |
| Tooltip | `property string tooltip` on every control; shown via `Tk.ToolTip` attached on hover; also the accessible name for icon-only controls. |
| Icons | `iconName` (Lucide name, see `qtk-preview --list-icons`) rendered by `Tk.Icon` at `size.icon` (14) or `size.iconSm` (12) when `small`. |
| Motion | colour/opacity transitions `Tk.Theme.motion.fast`; nothing longer than `motion.base` in chrome. |
| Naming | `iconName`, `trailingIconName`, `text`, `small`, `large`, `variant`, `checked`, `tooltip`, `value/from/to/stepSize`. Signals in past tense (`clicked`, `activated`, `valueModified`, `closed`). |
| objectName | Not set by the control; internal parts that tests need are named in the tables below. |

Layout primitives (`Flex`, `Grid`, `Stack`, `Box`, `Scroll`) are documented
in [layout.md](layout.md); theming in [theming.md](theming.md); docking in
[docking.md](docking.md).

## Buttons and chips

| Type | Base | Properties | Signals | Size / look |
| --- | --- | --- | --- | --- |
| `Button` | T.Button | `text`, `iconName`, `trailingIconName`, `variant` (`"default"`, `"accent"`, `"ghost"`, `"outline"`, `"danger"`), `small`, `large`, `busy`, `available` (capability; `enabled` is owned by the busy binding), `tooltip`, `checkable/checked` | `clicked` | 24px, padding-x `space.md`, radius sm, body font, icon 14 with `space.xs+2` gap. `busy` shows a `Spinner` in place of the icon and disables. `accent` = accent fill + `accentContrast` text; `danger` = danger fill; `ghost` = no fill/border at rest; `outline` = border only. |
| `Chip` | T.AbstractButton | `text`, `iconName`, `chevron`, `active` (alias of checked), `checkable`, `emphasis` (`"plain"`, `"tinted"`, `"solid"`), `rounded`, `small`, `tooltip` | `clicked` | The Sloom pill: 32px (small 28), radius 6, `chipBg/chipBorder`, hover `chipHover*`, label and icon in accent colour, 6px gap, padding-x 8. `rounded` is the 36px fully round island action (10px padding, transparent at rest, `panel` on hover, text colour until lit). `emphasis`: "tinted" = chipBg + controlActiveBorder, "solid" = controlActiveBg + controlActiveBorder; `active` lights the accent border. |
| `Segmented` | Item | `model` (list of strings or `{text, iconName, value, tooltip}`), `currentIndex`, `currentValue` (read), `small`, `stretch`, `tooltip` | `activated(index)` (user clicks only) | one 24px (small 20) row of joined segments in a `controlBg` frame; selected segment `controlActiveBg`, seams between unselected neighbours. objectName `segment_<index>` per segment. `stretch: true` fills the width it is given; inside a Flex row also set `Tk.Flex.grow: 1` so it is given one. |
| `ToolBar` | Box | `compact` (28 instead of 36), `gap`, `edge` (`"bottom"` border by default, `"top"`, `"none"`); default property `items` | — | horizontal Flex, `align: Center`, `space.sm` side padding, background `surface`. |
| `ToolSeparator` | Item | `inset`, `margin` | — | 1px vertical rule inset 6px from the bar edges; an Item that stretches on the cross axis (not a Divider) so the inset is measured from the bar, not the row's content height. |
| `Badge` | Rectangle | `text`, `variant` (`"default"`, `"accent"`, `"danger"`, `"success"`, `"warning"`, `"info"`), `dot`, `tooltip` | — | 16px tall (`size.controlSm - space.sm`, so it scales), radius full, micro font, semibold; `dot` is an 8px status dot. |
| `ProgressBar` | T.ProgressBar | `value`, `from`, `to`, `indeterminate`, `thin`, `tooltip` | — | 3px track (`thin` 2px), accent bar, radius full; the indeterminate slide stays off when reduced motion zeroes the motion ladder. |
| `Spinner` | T.BusyIndicator | `size` (14), `running`, `color`, `tooltip` | — | rotating `loader-circle` arc in accent; stops (stays visible) under reduced motion. |

| `Switch` | T.Switch | `text`, `checked`, `small`, `tooltip` | `toggled` | 26x14 track (22x12 small; derived from the icon sizes so it scales), radius full, accent when on; 10px (8px) knob; row height 20 (small 16). |
| `RadioButton` | T.RadioButton | `text`, `checked`, `small`, `tooltip` | `toggled` | 14px circle (12 small) with a half-size accent dot; row height 20 (small 16). |
| `TextField` | T.TextField | `placeholderText`, `text`, `iconName` (leading), `clearable`, `small`, `error`, `mono`, `tooltip`, `trailing` (slot) | `accepted`, `editingFinished`, `cleared` | 24px, `inputBg/inputBorder`, focus `inputFocusBorder` + ring, padding-x `space.sm+2`; placeholder muted at the *small* size (caption when `small`) so it lines up with typed text. `clearText()` clears and emits `cleared`; Escape clears when `clearable`. The control *is* the text input; the clear button is objectName `fieldClear`. Interactive parts are direct children, never inside `background` (T.TextField keeps its background at z -1). |
| `SearchField` | TextField | + `debounce` (ms, default 150) | `searched(text)` | search icon leading, clearable, Escape clears; `searched` fires after the debounce, immediately on Enter, and with "" on clear. |
| `TextArea` | T.TextArea | `placeholderText`, `text`, `rows` (min visible rows, 3), `mono`, `error`, `tooltip`; read-only `minimumHeight` | `editingFinished` | wraps and grows with its text from `rows` lines; place inside `Tk.Scroll` for long text. Default width 240. |
| `NumberField` | T.Control | `value`, `from`, `to`, `stepSize`, `decimals`, `prefix`, `suffix`, `label` (short inline label, e.g. "W"), `editable`, `scrub` (drag horizontally on the label/field to change), `scrubSensitivity` (units per px, default `stepSize`), `stepButtons` (show ▲▼ on hover), `small`, `error`, `tooltip`, `live`; read-only `editing`, `inputItem` | `valueModified(value)` (user edits only), `editingFinished` | 24px; mono digits; Ctrl+wheel steps; arrow keys step, Shift ×10, Alt ×0.1; Escape reverts the typed text. | `Slider` | T.Slider | `value`, `from`, `to`, `stepSize`, `showValue`, `decimals`, `suffix`, `small`, `tooltip` | `moved`, `valueModified(value)` | 2px track, 10px round handle (8 small), accent fill; `showValue` adds a mono readout right (it takes `rightPadding`). Height 16 (14 small) — sits in 24px rows. Horizontal only. |
| `ComboBox` | T.ComboBox | `model`, `currentIndex`, `currentText`, `textRole`, `iconRole`, `editable`, `small`, `placeholderText`, `tooltip` | `activated(index)` | 24px on `inputBg`, chevron-down trailing; popup = Menu-styled list (`popoverBg`, `popoverBorder`, radius md), rows `size.menuItem` (22), max 12 rows then scroll; the current row shows a check. A JS array of strings needs no roles. objectName `comboPopup` on the popup. |
| `ColorField` | T.Control | `color`, `showHex`, `small`, `error`, `tooltip` | `colorEdited(color)`, `pickRequested()` | 16px swatch (checkerboard behind alpha, objectName `colorSwatch`) + a bare mono hex input inside the field's own frame (objectName `colorHex`; `#rgb`, `#rrggbb`, `#aarrggbb`, bare hex accepted; Escape reverts); `applyHex(text)` is the programmatic entry point. Tapping the swatch emits `pickRequested()`. |
