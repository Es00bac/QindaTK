# Controls catalog and API contract

Every QindaTK control is a QML type in `src/qml/` with the same name as the
file. Import with `import QindaTK as Tk`. This page is the contract: names,
properties, signals, sizes. `docs/catalog.json` is the machine-readable
mirror generated by `tools/scripts/gen_catalog.py`; keep both current.

## Conventions shared by all controls

| Convention | Rule |
| --- | --- |
| Base | `QtQuick.Templates as T` types for anything interactive; `Item`/`Rectangle` for passive pieces. |
| Height | `Tk.Theme.size.control` (24). `small: true` → `controlSm` (20). `large: true` → `controlLg` (28). Chips 32 (`size.chip`), island actions 36 (`size.action`), rows 22 (`size.row`), headers 24 (`size.header`), tabs 22 (`size.tab`). |
| Text | body 12px (`font.body`); captions 10px; overlines 10px uppercase semibold tracked. |
| Radius | `radius.sm` (4) for controls, `radius.md` (6) for chips/panels/popovers, `radius.full` for islands, badges, switches. |
| Colours | Only `Tk.Theme.color.*` roles. Rest: `controlBg`/`controlBorder`; hover: `controlHoverBg`/`controlHoverBorder`; active/checked: `controlActiveBg`/`controlActiveBorder`; inputs: `inputBg`/`inputBorder`/`inputFocusBorder`; chips: `chipBg`/`chipBorder`/`chipHoverBg`/`chipHoverBorder`. |
| Focus | 2px `Tk.Theme.color.focus` ring 1px outside the background, shown on `visualFocus`. |
| Disabled | `opacity: Tk.Theme.opacity.disabled`. |
| Tooltip | `property string tooltip` on every control; shown via `Tk.ToolTip` attached on hover; also the accessible name for icon-only controls. |
| Icons | `iconName` (Lucide name, see `qtk-preview --list-icons`) rendered by `Tk.Icon` at `size.icon` (14) or `size.iconSm` (12) when `small`. |
| Motion | colour/opacity transitions `Tk.Theme.motion.fast`; nothing longer than `motion.base` in chrome. |
| Naming | `iconName`, `trailingIconName`, `text`, `small`, `large`, `variant`, `checked`, `tooltip`, `value/from/to/stepSize`. Signals in past tense (`clicked`, `activated`, `valueModified`, `closed`). |
| objectName | Not set by the control; internal parts that tests need are named in the tables below. |

Layout primitives (`Flex`, `Grid`, `Stack`, `Box`, `Scroll`) are documented
in [layout.md](layout.md); theming in [theming.md](theming.md); docking in
[docking.md](docking.md).

## Telemetry

Readings over time and against a limit. `Tk.Graph` draws on the scene graph;
`Tk.Meter` is a `QQuickPaintedItem`. Both take a `Tk.Theme.ramp.*` scale (see
[theming.md](theming.md)) so a value is coloured by its magnitude.
