## Caveats
- **Not run on the phone.** `adb devices` listed no device for about 40 minutes (no Samsung USB
  device in lsusb, no mDNS service), so requirement 3 (install, launch, screencap, inspect) is open.
  Nothing was installed or changed on the phone. APK:
  `build/android-sign/qindatk-smoke-debug.apk` in the worktree (ignored), keystore beside it.
- Qt for Android here has no SSL (`QT_NO_SSL`, only the qcertonly TLS backend). QindaLink's pinned
  TLS needs its own TLS stack or a Qt with OpenSSL. This affects the phone-engine lane.
- Quick3D and ShaderTools are available in this Qt but OFF in the preset (a phone UI does not need them).
- Release libs keep `-g` (531 MB unstripped); androiddeployqt strips for the APK (39 MB).
